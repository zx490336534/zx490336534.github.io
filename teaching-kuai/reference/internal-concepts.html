🏢 1. 三仓库职责与数据流

仓库技术栈职责存储
后端 kuai-serviceJava 8 + Spring Boot + MyBatis-Plus + TDDLPrompt 管理、LLM 评估、微信机器人、知识库 API、分享应用MySQL(TDDL) + MongoDB
前端 kuai-service-frontNext.js 16 + React 18 + LangChain + Ant Design 6对话 UI、LangChain Agent、MCP 工具前端执行、Prompt 编辑、技能系统、Claude CodeMongoDB（会话）
Python kuai-service-pyPython 3.12 + FastAPI + mcp[cli] 1.12 + langchain/langgraph多协议 MCP Server 网关，统一 HTTP 接口管理多个 MCP 服务器MySQL(aiomysql) + chromadb 向量库
数据流（对话一次调用）
前端发起对话 → LangChain Agent 决策（LangGraph 编排） → 需要工具时经 MCP（py 网关统一管理）或直接调后端 API 执行 → 结果流式回传前端（streamdown / Vercel AI SDK 渲染） → Prompt / 评估 / 知识库 / 会话持久化走后端（kuai-service）

🤖 2. Agent-First 架构（前端核心）

前端以 Agent 为中心组织能力，多个 Agent 框架并存：

  • LangChain 1.4 + LangGraph 1.3 — createReactAgent、Tool、流式对话的主力框架。
  • @anthropic-ai/claude-agent-sdk 0.2.90 — 代码分析型 Agent（Claude Code 集成）。
  • Vercel AI SDK（ai 6.x） — UI 层流式渲染与模型适配。
  • 工具来源 — @langchain/mcp-adapters（MCP 工具）+ 自定义工具。

详见：0006 Agent 系统、0007 MCP 工具集成、0030 Claude Code 集成。

🔌 3. MCP 多协议网关（Python 服务）

kuai-service-py 基于 mcp[cli]==1.12.0 统一管理多个 MCP Server，对外暴露一致 HTTP 接口：

传输方式说明
SSEServer-Sent Events，sse-starlette 实现，长连接流式。
Stdio本地子进程标准输入输出，适合本地工具。
StreamableHTTPHTTP 流式，可穿透网关/代理。

服务器生命周期为状态机：启动 → 健康检查 → 运行 →（异常）重启。详见 0010 概览、0011 MCP 服务架构、0025 传输协议、0026 生命周期。

协议基础概念见 MCP 协议基础。

📝 4. Prompt 版本管理（后端）

  • Prompt + PromptVersion：版本管理、发布/下线、A/B 测试、评估记录。
  • 调用链：PromptController → PromptService → PromptMapper。

详见 0016 Prompt 管理系统、前端 0021 Prompt 管理界面。

📊 5. LLM 评估（后端 + Python）

  • 单次 + 批量：@EnableAsync + CompletableFuture 并发执行，可自定义评估模型。
  • DeepEval：另一种评估路径（后端 DeepEval 控制器 + Python deepeval）。
  • 调用链：LLMEvaluationController → LLMEvaluationService → LlmTaskMapper。

详见 0017 LLM 评估系统。

📚 6. 知识库 / 分享应用

  • SharedAppService（2700+ 行核心服务）：分享配置、对话历史、标签分类、评估统计。
  • MongoDB：存大量非结构化对话数据。
  • Python 侧：chromadb 向量库 + deepeval，支撑知识检索与评估。

详见 0019 知识库与分享应用、0020 数据库设计。

💬 7. 微信机器人（后端）

  • 企业微信：群聊/私聊 Token 注册、FastGPT 代理调用、长连接管理、流式回复。
  • 调用链：WeChatRobotController → RobotChatService → NewRobotMapper。

详见 0018 微信机器人集成。

📦 9. 三仓库本地路径

../gitproject/kuai-service          # Java 后端
../gitproject/kuai-service-front    # Next.js 前端
../gitproject/kuai-service-py       # Python MCP 服务

引用源码用仓库相对路径，如 kuai-service/src/main/java/com/qunhe/kuai/...。

易错点
  • 后端是 Java 8，讲 Spring 时不要套用 Java 17+ 语法。
  • 前端是 React 18 + Tailwind 4 + shadcn（与 Ant Design 6 并存），不止 CSS Modules。
  • Python 服务也用 langchain/langgraph + chromadb，并非纯 MCP。
  • 需求号是 HUXING-xxx，不是 AIHom 的 COOAI-xxx。
