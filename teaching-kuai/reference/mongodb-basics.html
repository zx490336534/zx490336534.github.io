MongoDB 基础入门

概念 面向零基础小白的 MongoDB 入门教程

本教程将带你了解 MongoDB 这个流行的 NoSQL 数据库。学完后你将理解文档/集合/数据库的核心概念，以及如何在 Spring Boot 项目中使用 Spring Data MongoDB。

📦 什么是 NoSQL

在学习 MongoDB 之前，我们先搞清楚一个前置概念：NoSQL。

SQL vs NoSQL

SQL（Structured Query Language）是传统关系型数据库的统称，比如 MySQL、PostgreSQL、Oracle。它们用表格（行和列）来存储数据。

NoSQL（Not Only SQL）是"不仅仅是 SQL"的意思，泛指非关系型数据库。它们不用固定的表格结构，数据存储方式更灵活。

一句话理解：如果 SQL 数据库像 Excel 表格（每行必须有相同的列），那 NoSQL 数据库就像一个文件夹，里面的每个文件可以有不同的内容。

常见的 NoSQL 数据库类型

类型代表产品特点
文档型MongoDB、CouchDB数据以 JSON 文档存储，灵活
键值型Redis、Memcached简单 key-value，速度极快
列族型Cassandra、HBase适合海量数据分析
图数据库Neo4j擅长处理关系网络

MongoDB 属于文档型数据库，是目前最流行的 NoSQL 数据库之一。

⚖️ MongoDB vs MySQL

很多初学者会问：既然有了 MySQL，为什么还需要 MongoDB？让我们来对比一下：

对比维度MySQL（关系型）MongoDB（文档型）
数据结构固定的表结构（Schema）灵活的文档结构（Schema-less）
存储格式行和列JSON/BSON 文档
查询语言SQLMongoDB Query Language
关联查询JOIN 非常强嵌套文档或 $lookup
扩展方式垂直扩展（加硬件）水平扩展（加机器）
事务支持完善的 ACID 事务4.0+ 支持多文档事务
适合场景结构化数据、复杂查询灵活数据、快速迭代
什么时候选 MongoDB？
- 数据结构经常变化（比如需求还在迭代中）
- 数据之间关系不复杂（不需要很多 JOIN）
- 需要存储 JSON 格式的数据（比如 API 响应、日志）
- 需要快速开发，不想先定义表结构

📄 文档 / 集合 / 数据库

MongoDB 有三个核心概念，理解了它们就理解了 MongoDB 的数据组织方式：

1. 文档（Document）

文档是 MongoDB 中最小的数据单元，就是一个 JSON 对象（技术上是 BSON，二进制 JSON）。

{
  "_id": "507f1f77bcf86cd799439011",
  "name": "张三",
  "age": 25,
  "hobbies": ["编程", "打游戏"],
  "address": {
    "city": "北京",
    "district": "海淀区"
  }
}
注意：每个文档都有一个 _id 字段作为唯一标识，类似 MySQL 的主键。如果你不提供，MongoDB 会自动生成一个。

2. 集合（Collection）

集合就是一组文档的"容器"，类似 MySQL 中的表（Table）。

  • 一个集合里的文档可以有不同的字段（不像 MySQL 每行必须有相同的列）
  • 通常我们会让同一个集合里的文档保持相似的结构
  • 集合名一般是复数形式，比如 users、orders

3. 数据库（Database）

数据库是集合的"容器"，一个 MongoDB 服务器可以有多个数据库。类似 MySQL 中的数据库概念。

MongoDB 服务器
├── 数据库: kuai_service
│   ├── 集合: users
│   │   ├── 文档: { name: "张三", age: 25 }
│   │   └── 文档: { name: "李四", age: 30 }
│   └── 集合: prompts
│       └── 文档: { title: "测试提示词", content: "..." }
└── 数据库: test_db
    └── 集合: logs
        └── 文档: { level: "info", message: "..." }
层级关系：数据库 → 集合 → 文档，就像 文件夹 → 子文件夹 → 文件。

🍃 Spring Data MongoDB

在 Spring Boot 项目中，我们可以使用 Spring Data MongoDB 来操作 MongoDB。它提供了三种主要方式：

1. @Document 注解 — 定义数据模型

@Document 注解用来标记一个 Java 类对应 MongoDB 中的哪个集合：

@Document(collection = "users")  // 对应 MongoDB 的 users 集合
public class User {
    @Id
    private String id;            // 对应 _id 字段
    private String name;
    private Integer age;
    private List<String> hobbies;
    
    // getter/setter 省略
}
类比：@Document 就像 MyBatis-Plus 的 @TableName，告诉框架"这个类对应数据库的哪个表（集合）"。

2. MongoTemplate — 灵活操作数据库

MongoTemplate 是一个功能强大的工具类，可以执行各种复杂的数据库操作：

@Service
public class UserService {
    
    @Autowired
    private MongoTemplate mongoTemplate;
    
    // 插入一条数据
    public User createUser(User user) {
        return mongoTemplate.insert(user);
    }
    
    // 查询：找名字为"张三"的用户
    public User findByName(String name) {
        Query query = new Query(Criteria.where("name").is(name));
        return mongoTemplate.findOne(query, User.class);
    }
    
    // 更新：修改年龄
    public void updateAge(String id, Integer age) {
        Query query = new Query(Criteria.where("id").is(id));
        Update update = new Update().set("age", age);
        mongoTemplate.updateFirst(query, update, User.class);
    }
    
    // 删除
    public void deleteUser(String id) {
        Query query = new Query(Criteria.where("id").is(id));
        mongoTemplate.remove(query, User.class);
    }
}

3. Repository — 自动实现查询

类似 Spring Data JPA 的 JpaRepository，只需要定义接口，Spring 会自动实现：

public interface UserRepository extends MongoRepository<User, String> {
    
    // 按名字查找 — 只需定义方法名，Spring 自动生成实现
    User findByName(String name);
    
    // 按年龄范围查找
    List<User> findByAgeBetween(Integer min, Integer max);
    
    // 按名字模糊查询
    List<User> findByNameContaining(String keyword);
    
    // 按年龄降序排列
    List<User> findAllByOrderByAgeDesc();
}
三种方式怎么选？
- 简单 CRUD → 用 Repository（最简单）
- 复杂查询/聚合 → 用 MongoTemplate（最灵活）
- 两者可以同时使用，互不冲突
