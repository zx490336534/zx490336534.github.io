LangChain 基础入门

概念 面向零基础小白的 LangChain 入门教程

本教程将带你了解 LangChain 这个 AI 应用开发框架。学完后你将理解核心概念（Model、Prompt、Chain、Agent、Tool），以及 ReAct 模式和 createReactAgent 的工作原理。

🦜 什么是 LangChain

LangChain 是一个用于构建 AI 应用的开源框架，它让你可以方便地把大语言模型（LLM）和外部工具、数据源组合起来，构建强大的 AI 应用。

一句话理解：如果大语言模型（如 ChatGPT）是一个"超级大脑"，那 LangChain 就是帮这个大脑连接"手脚"（工具）和"记忆"（知识库）的框架。

为什么需要 LangChain？

直接调用 LLM API（比如 OpenAI API）只能做简单的"问答"。但如果你想：

  • 让 AI 帮你查数据库再回答问题
  • 让 AI 帮你调用 API（比如发邮件、查天气）
  • 让 AI 读取文档后回答问题（RAG）
  • 让 AI 多步推理，自主决定下一步做什么

这些场景下，直接用 API 会非常复杂。LangChain 提供了一套工具和抽象，让这些变得简单。

🧩 核心概念

LangChain 有 5 个核心概念，理解了它们就理解了整个框架：

Model + Prompt → Chain → Agent → Tool

1. Model（模型）

Model 是 LangChain 的"大脑"，就是你调用的大语言模型。LangChain 支持对接各种 LLM：

  • OpenAI（GPT-4、GPT-3.5）
  • Anthropic（Claude）
  • Google（Gemini）
  • 本地模型（Ollama 等）
import { ChatOpenAI } from "@langchain/openai";

const model = new ChatOpenAI({
  modelName: "gpt-4",
  temperature: 0.7,  // 0=确定性高，1=更有创意
});
类比：Model 就像一个员工的大脑。你可以换不同的"大脑"（GPT-4、Claude 等），但接口是一样的。

2. Prompt（提示词模板）

Prompt 是你给 LLM 的"指令"。LangChain 提供了模板系统，可以动态生成提示词：

import { ChatPromptTemplate } from "@langchain/core/prompts";

// 定义一个模板，{product} 是变量
const prompt = ChatPromptTemplate.fromMessages([
  ["system", "你是一个产品分析师"],
  ["user", "请分析这个产品的优缺点：{product}"]
]);

// 使用时填入变量
const message = await prompt.invoke({
  product: "iPhone 16"
});

3. Chain（链）

Chain 是把 Model 和 Prompt 串联起来的管道。最简单的 Chain = Prompt + Model + 输出解析。

import { ChatOpenAI } from "@langchain/openai";
import { ChatPromptTemplate } from "@langchain/core/prompts";
import { StringOutputParser } from "@langchain/core/output_parsers";

const model = new ChatOpenAI({ modelName: "gpt-4" });
const prompt = ChatPromptTemplate.fromMessages([
  ["user", "用一句话解释什么是{concept}"]
]);
const parser = new StringOutputParser();

// 用 | 管道符把它们串起来
const chain = prompt | model | parser;

// 调用链
const result = await chain.invoke({ concept: "量子计算" });
console.log(result);  // "量子计算是利用量子力学原理进行计算的技术..."
管道符 | 的理解：就像 Unix 的管道 cat file | grep "hello" | sort，数据从左到右流过每一步。

4. Agent（智能体）

Agent 是 LangChain 最强大的概念。它让 LLM 能够自主决策——根据用户的问题，自己决定要不要调用工具、调用哪个工具。

Chain vs Agent 的区别：
- Chain：固定的流程，A → B → C，每次都是同样的步骤
- Agent：动态的流程，LLM 自己决定下一步做什么

5. Tool（工具）

Tool 是 Agent 可以使用的"工具"，比如搜索、查数据库、调 API 等。你可以自定义工具：

import { tool } from "@langchain/core/tools";
import { z } from "zod";

// 定义一个"查天气"工具
const weatherTool = tool(
  async ({ city }) => {
    // 调用天气 API
    const weather = await fetchWeather(city);
    return `${city}今天天气：${weather.temp}°C，${weather.desc}`;
  },
  {
    name: "get_weather",
    description: "查询指定城市的天气信息",
    schema: z.object({
      city: z.string().describe("城市名称"),
    }),
  }
);

🧠 ReAct 模式（推理 + 行动）

ReAct（Reasoning + Acting）是 Agent 的核心工作模式。它的名字来自两个词的组合：

  • Reasoning（推理）：思考当前应该做什么
  • Acting（行动）：执行具体的工具调用

ReAct 的工作流程

当用户提出一个问题时，Agent 会按照以下步骤工作：

用户问题："北京今天天气怎么样？适合穿什么？"


🔄 第 1 轮：推理 + 行动

🤔 思考：用户问的是北京天气，我需要调用天气工具

🔧 行动：调用 get_weather("北京")

📋 观察：北京今天 28°C，晴天


🔄 第 2 轮：推理 + 行动

🤔 思考：已获取天气，28°C 晴天，可以给出穿衣建议

✅ 最终回答：北京今天 28°C 晴天，建议穿短袖、注意防晒。

ReAct 就像人类解决问题的方式：先想（推理），再做（行动），看看结果（观察），然后继续想...直到找到答案。

ReAct vs 普通对话

对比普通 ChatGPT 对话ReAct Agent
能力只能用训练数据回答可以调用外部工具获取实时数据
推理一步到位多步推理，逐步解决
准确性可能编造（幻觉）基于工具返回的真实数据
灵活性固定根据情况动态选择工具

🤖 createReactAgent 是什么

createReactAgent 是 LangChain 提供的一个开箱即用的函数，用来快速创建一个使用 ReAct 模式的 Agent。

import { createReactAgent } from "@langchain/langgraph/prebuilt";
import { ChatOpenAI } from "@langchain/openai";

// 1. 准备模型
const model = new ChatOpenAI({ modelName: "gpt-4" });

// 2. 准备工具
const tools = [weatherTool, searchTool, calculatorTool];

// 3. 创建 ReAct Agent
const agent = createReactAgent({
  llm: model,        // 用哪个大脑
  tools: tools,      // 有哪些工具可用
});

// 4. 使用 Agent
const result = await agent.invoke({
  messages: [{ role: "user", content: "北京今天适合穿什么？" }]
});

createReactAgent 帮你做了什么？

这个函数内部自动做了很多工作：

  1. 生成系统提示词：告诉 LLM "你是一个 Agent，可以用这些工具..."
  2. 解析工具调用：当 LLM 决定调用工具时，自动执行并返回结果
  3. 管理对话状态：维护多轮对话的消息历史
  4. 循环执行：自动实现"推理 → 行动 → 观察"的循环，直到得到最终答案
在我们的项目中：kuai-service-front 使用 createReactAgent 来创建 AI 助手 Agent，它集成了 MCP 工具，可以帮你查数据、执行操作等。
