🔴 Redis 基础入门

概念 从零了解 Redis，掌握核心数据结构和 Spring Boot 集成方式

🤔 什么是 Redis？

Redis（Remote Dictionary Server）是一个开源的内存数据库。和 MySQL 不同，Redis 把数据存在内存里，所以读写速度极快，通常在微秒级别。

用一个生活中的比喻：

📦 快递柜比喻

MySQL 就像仓库货架 —— 存储量大，但找东西要走过去拿，比较慢。
Redis 就像你家门口的快递柜 —— 东西就在手边，一按就取出来，非常快。但快递柜空间有限，不可能存下所有快递。

Redis 的核心特点：

  • 极快：数据存在内存中，读写速度比 MySQL 快 10~100 倍
  • 丰富的数据结构：不只是简单的 Key-Value，还支持 Hash、List、Set 等
  • 持久化：虽然数据在内存里，但可以定期保存到磁盘，防止丢失
  • 单线程模型：避免了多线程的锁竞争问题，反而更快更简单

💡 为什么用 Redis？

Redis 最常见的三大用途：

2.1 缓存 —— 加速数据访问

这是 Redis 最经典的用途。查询数据库很慢，但查 Redis 很快。所以我们可以把热点数据（经常被访问的数据）存到 Redis 里：

// 查询用户信息的伪代码
public User getUser(Long id) {
    // 第一步：先查 Redis
    String json = redis.get("user:" + id);
    if (json != null) {
        return parse(json);  // 命中缓存，直接返回
    }
    // 第二步：Redis 没有，再查数据库
    User user = userDao.selectById(id);
    // 第三步：把结果存到 Redis，下次就不用查库了
    redis.set("user:" + id, toJson(user), 3600);  // 缓存 1 小时
    return user;
}

🏠 缓存的生活比喻

缓存就像你把常用的书放在书桌上（Redis），不常用的放在书架上（MySQL）。用完放回去，下次随手就能拿到。

2.2 分布式锁 —— 防止重复操作

在分布式系统中（多个服务器同时运行），需要一种机制来保证同一时刻只有一个服务器能执行某个操作（比如扣减库存、创建订单）。Redis 可以用 SETNX 命令实现分布式锁：

// 伪代码：用 Redis 实现分布式锁
boolean locked = redis.set("lock:order:create", "1", 30, "NX");
// NX = 不存在才设置，相当于"抢锁"
if (locked) {
    try {
        createOrder();  // 拿到锁了，执行业务
    } finally {
        redis.del("lock:order:create");  // 用完释放锁
    }
} else {
    // 没拿到锁，提示稍后重试
}

2.3 会话存储 —— 保存用户登录状态

用户登录后，服务器会生成一个 Session（会话）来记住"这个用户已经登录了"。传统方式把 Session 存在服务器内存里，但如果有多台服务器，用户的请求可能被分配到不同的服务器，导致 Session 丢失。

把 Session 存到 Redis 就解决了这个问题 —— 所有服务器都从同一个 Redis 读取 Session：

// Spring Boot 中配置 Session 存储到 Redis
// 只需要引入 spring-session-data-redis 依赖即可
// application.yml:
spring:
  session:
    store-type: redis

🧩 核心数据结构

Redis 不只是简单的 Key-Value 存储，它支持 4 种常用数据结构：

数据结构类比典型用途
String一个抽屉放一个东西缓存单个值、计数器、分布式锁
Hash一个抽屉里有多个小格子存储对象（用户信息、商品信息）
List排队队列消息队列、最新动态列表
Set不允许重复的集合标签、共同好友、去重

3.1 String —— 最基本的类型

# 存值
SET user:1:name "张三"

# 取值
GET user:1:name    → "张三"

# 设置过期时间（3600 秒后自动删除）
SET token:abc123 "user_1" EX 3600

# 计数器（比如文章点赞数）
INCR article:1001:likes    → 1
INCR article:1001:likes    → 2
INCR article:1001:likes    → 3

3.2 Hash —— 存储对象

# 存储用户信息（类似 Java 的 Map）
HSET user:1 name "张三"
HSET user:1 age 25
HSET user:1 email "zhangsan@example.com"

# 获取单个字段
HGET user:1 name    → "张三"

# 获取所有字段
HGETALL user:1
→ {name: "张三", age: 25, email: "zhangsan@example.com"}

String vs Hash 怎么选？

如果只需要存一个值，用 String；如果需要存一个对象的多个字段，用 Hash。Hash 的好处是可以只更新某个字段，不用取出整个对象。

3.3 List —— 有序列表

# 从左边插入（像排队一样）
LPUSH messages "消息1"
LPUSH messages "消息2"
LPUSH messages "消息3"

# 获取列表（0 到 2，共 3 条）
LRANGE messages 0 2
→ ["消息3", "消息2", "消息1"]  # 最新的在前面

# 从右边取出（FIFO 先进先出）
RPOP messages → "消息1"

3.4 Set —— 无序不重复集合

# 添加标签
SADD article:1:tags "Java"
SADD article:1:tags "Redis"
SADD article:1:tags "Spring"

# 获取所有标签
SMEMBERS article:1:tags → {"Java", "Redis", "Spring"}

# 判断是否包含某个标签
SISMEMBER article:1:tags "Redis" → 1 (true)

# 两个集合求交集（比如共同好友）
SINTER user:1:friends user:2:friends

🚀 Spring Boot 集成 Redis

在 Spring Boot 中使用 Redis 非常简单，主要通过 RedisTemplate 来操作。

第一步：引入依赖

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-redis</artifactId>
</dependency>

第二步：配置连接信息

# application.yml
spring:
  data:
    redis:
      host: localhost
      port: 6379
      password: your_password
      database: 0

第三步：使用 RedisTemplate

@Service
public class CacheService {

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    // 存值
    public void set(String key, Object value, long seconds) {
        redisTemplate.opsForValue().set(key, value, seconds, TimeUnit.SECONDS);
    }

    // 取值
    public Object get(String key) {
        return redisTemplate.opsForValue().get(key);
    }

    // 删除
    public void delete(String key) {
        redisTemplate.delete(key);
    }

    // 判断是否存在
    public boolean hasKey(String key) {
        return Boolean.TRUE.equals(redisTemplate.hasKey(key));
    }
}

opsFor 系列方法

RedisTemplate 提供了不同数据结构的操作方法：

// String 操作
redisTemplate.opsForValue().set("key", "value");
redisTemplate.opsForValue().get("key");

// Hash 操作
redisTemplate.opsForHash().put("user:1", "name", "张三");
redisTemplate.opsForHash().get("user:1", "name");

// List 操作
redisTemplate.opsForList().leftPush("queue", "msg");
redisTemplate.opsForList().rightPop("queue");

// Set 操作
redisTemplate.opsForSet().add("tags", "Java", "Redis");
redisTemplate.opsForSet().members("tags");
