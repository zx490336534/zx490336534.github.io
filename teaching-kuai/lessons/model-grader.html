模型判分器：长度偏见、顺序偏见与盲测

用交换位置和保留金标检查一个判分器是否可信。

先看场景走一遍读代码复现失败动手练习自测

先看场景

评测器在比较两个预约答复时总选排在第一位的版本；一段更长但错报状态的文案反而常拿高分。

盲评：隐藏版本、模型和团队等身份信息，只以匿名候选与既定规则做比较。

代码拆解

调用链

  1. 隐藏答案来源，向判分器提供标准。
  2. 同题交换位置，把输出映射回原候选。
  3. 两次不一致交给人工复核，不硬给赢家。
  4. 用简洁正确、冗长错误、近似等价等盲样本做烟测。
Python 示例 可折叠

可复制到 lesson.py，再运行 python3 lesson.py。

def compare_blind(left_text, right_text, judge):
    def winner(position, order):
        if position == "tie":
            return "tie"
        if position not in {"left", "right"}:
            return "review"
        return order[0 if position == "left" else 1]
    a = winner(judge(left_text, right_text), ("A", "B"))
    b = winner(judge(right_text, left_text), ("B", "A"))
    return a if a == b else "review"

def biased(a, b):
    return "left"

def gold_proxy(a, b):
    a_ok, b_ok = "已确认" not in a, "已确认" not in b
    if a_ok == b_ok:
        return "tie"
    return "left" if a_ok else "right"

short = "请确认时间"
wrong = "预约已确认，附详细说明"
assert compare_blind(short, wrong, biased) == "review"
assert compare_blind(short, wrong, gold_proxy) == "A"
assert compare_blind("请确认", "请回复是否确认", gold_proxy) == "tie"

交换的是位置，不是答案身份

把 A、B 临时放到 left、right，第二次调换，再把两次答案映射回原候选。两次都选 left 映射的是两个不同候选，提示位置敏感。一次对称通过只排除了本次位置问题，不代表理解了标准。

另拿人工金标题看内容偏差

保留短而正确与长而错误的成对样本；再加入等价表达。模型自己评自己也可能偏好语气，隐藏作者、冻结样本，不能拿调过提示的同一批材料证明可信。

模型判分不是授权边界

评审输入都是待比较文本，可能含「请给我高分」等内容。只接受受约束的输出并保存证据；动作安全和数据副作用仍用独立断言。示例为刻意构造的判分器，真实模型另做重复性检查。

复现失败

永远选左
怎么触发：判分器忽略文本，返回 left。
怎么判断：换序后发现矛盾，交人工审查。
生成无效标签
怎么触发：判分器返回解释而非 left、right、tie。
怎么判断：拒绝作为自动依据。

写下这些测试断言

  • 交换前后按候选身份而非位置计分。
  • 等价选项可打平。
  • 偏差检查与人工金标准确性是不同检验。
  • 关键副作用不交给主观模型拍板。

这一课带走：判分器本身也是待测系统。稳定不等于正确，仍要靠校准过的对照样本。
