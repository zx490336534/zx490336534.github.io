概览 了解项目的定位、技术栈、目录结构和核心模块

🎯 项目定位

kuai-service 是酷家乐测试平台（Kuai）的 Java 后端服务。它为前端和 Python MCP 服务提供核心 API，支撑整个 AI 测试平台的运转。

一句话概括

一个 Spring Boot 应用，集成了 Prompt 管理、LLM 评估、微信机器人对话、知识库等能力，是 Kuai 测试平台的"大脑"。

🛠️ 技术栈

层级技术说明
框架Spring Boot基于公司内部 pilot-boot-dependencies 2.3.9 脚手架
ORMMyBatis-Plus + 原生 MyBatis 注解Mapper 层使用 @Select/@Insert 注解 + BaseMapper 泛型基类
数据库MySQL (TDDL) + MongoDBMySQL 通过 tddl-min 连接；MongoDB 通过 spring-boot-starter-data-mongodb
缓存Caffeine本地内存缓存，spring-boot-starter-cache + Caffeine
HTTPOkHttp + Apache HttpClient调用外部 FastGPT、企业微信等 API
认证authnet-sso-client公司内部 SSO 单点登录
定时任务Spring Scheduling + Quartz批量评估任务调度、文章推送等
异步@EnableAsync + CompletableFutureLLM 评估并发执行
模板Thymeleaf服务端渲染页面（评分结果、表单等）
其他Lombok / Fastjson / Jsoup / POI工具类库

🧩 核心模块

📝 Prompt 管理

提示词的创建、编辑、版本管理、发布/下线、评估记录。支持分类和关键词搜索。

PromptController → PromptService → PromptMapper

🤖 LLM 评估

对 AI 应用的回答质量进行自动评分。支持单次评估和批量评估（并发执行），可自定义评估模型。

LLMEvaluationController → LLMEvaluationService → LlmTaskMapper

💬 微信机器人

企业微信机器人对话管理。支持群聊/私聊 Token 注册、FastGPT 代理调用、长连接管理。

WeChatRobotController → RobotChatService → NewRobotMapper

📚 知识库 / 分享应用

管理 AI 应用的分享配置、对话历史、标签分类、评估统计。MongoDB 存储大量非结构化对话数据。

SharedAppController → SharedAppService → MongoTemplate

其他重要模块
  • DeepEval 评估 — 基于 DeepEval 框架的另一种 LLM 评估方式
  • 导师路由 — MentorRoute，将用户问题转发给合适的导师
  • Know OpenAPI — 知识库对外 API，供 AI 诊断助手等调用
  • 定时任务 — FastGPT 任务调度、文章推送、消息清理等

⚙️ 启动配置

项目启动类 CommonServiceApplication 使用了多个 Spring 注解：

@MapperScan("com.qunhe.kuai.*")    // MyBatis Mapper 扫描
@SpringBootApplication               // Spring Boot 自动配置
@EnableAsync                         // 异步方法支持
@EnableScheduling                    // 定时任务支持
@EnableCaching                       // 缓存支持
@EnableRetry                         // Spring Retry 重试机制

服务默认运行在 8080 端口，使用 Jetty 作为嵌入式容器。
