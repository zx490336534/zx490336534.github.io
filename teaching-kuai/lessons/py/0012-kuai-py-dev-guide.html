实战 动手做：新增 MCP 服务器、新增分组、本地运行与调试技巧

➕ 如何新增 MCP 服务器

新增 MCP 服务器是最常见的开发任务。你需要通过 API 向系统注册一个服务器配置，系统会自动建立连接并加载工具。

方式一：通过 REST API 添加

1 确定传输协议

根据你的 MCP 服务器类型选择合适的传输协议：

场景传输类型必填字段
远程 HTTP SSE 服务器sseurl
本地命令行工具stdiocommand, args
远程 StreamableHTTP 服务器streamable_httpurl
2 调用创建 API 
# SSE 服务器示例
curl -X POST http://localhost:8000/servers/ \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-sse-server",
    "transport": "sse",
    "url": "http://localhost:3000/sse",
    "enabled": true,
    "auto_start": true
  }'

# Stdio 服务器示例（本地 MCP 工具）
curl -X POST http://localhost:8000/servers/ \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-stdio-server",
    "transport": "stdio",
    "command": "python",
    "args": ["-m", "my_mcp_tool"],
    "env": {"API_KEY": "xxx"},
    "enabled": true,
    "auto_start": true
  }'

# StreamableHTTP 服务器示例
curl -X POST http://localhost:8000/servers/ \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-http-server",
    "transport": "streamable_http",
    "url": "http://localhost:4000/mcp",
    "headers": {"Authorization": "Bearer token123"},
    "enabled": true,
    "auto_start": true
  }'
3 验证服务器状态 
# 查看所有服务器状态
curl http://localhost:8000/servers/

# 查看特定服务器详情
curl http://localhost:8000/servers/my-sse-server

# 健康检查
curl http://localhost:8000/servers/my-sse-server/health

# 查看诊断信息
curl http://localhost:8000/servers/my-sse-server/diagnostics

方式二：通过代码添加

from src.models import ServerConfig, TransportType

config = ServerConfig(
    name="my-server",
    transport=TransportType.SSE,       # 或 STDIO / STREAMABLE_HTTP
    url="http://localhost:3000/sse",
    enabled=True,
    auto_start=True,
    timeout=30000,                     # 超时时间（毫秒）
    keep_alive_interval=60000          # 心跳间隔（毫秒）
)

success = await mcp_service.add_server(config)

服务器管理操作

# 启动/停止/重启
POST /servers/{name}/start
POST /servers/{name}/stop
POST /servers/{name}/restart

# 更新配置
PUT /servers/{name}
{
  "url": "http://new-url:3000/sse",
  "timeout": 60000
}

# 删除服务器
DELETE /servers/{name}

📂 如何新增分组

分组将多个 MCP 服务器组织在一起，可以指定每个服务器暴露哪些工具，然后以一个统一的 MCP 端点对外提供服务。

创建分组

curl -X POST http://localhost:8000/groups/ \
  -H "Content-Type: application/json" \
  -d '{
    "name": "development",
    "description": "开发环境工具组",
    "servers": [
      {
        "name": "my-sse-server",
        "tools": "all",
        "enabled": true
      },
      {
        "name": "my-stdio-server",
        "tools": ["read_file", "write_file"],
        "enabled": true
      }
    ]
  }'

工具过滤说明

tools 值含义示例
"all"暴露该服务器的所有工具"tools": "all"
[]（空列表）等同于 "all""tools": []
["tool1", "tool2"]只暴露指定的工具"tools": ["read_file", "list_files"]

分组管理操作

# 获取所有分组
GET /groups/

# 获取分组详情
GET /groups/{group_id}

# 向分组添加服务器
POST /groups/{group_id}/servers
{
  "name": "another-server",
  "tools": ["specific_tool"],
  "enabled": true
}

# 从分组移除服务器
DELETE /groups/{group_id}/servers/{server_name}

# 删除分组
DELETE /groups/{group_id}

# 通过 MCP 协议访问分组（SSE 端点）
GET /groups/{group_id}/mcp

AI Agent 对话

分组端点还集成了 LangChain Agent，支持自然语言对话并自动调用工具：

# AI 对话（自动工具调用）
POST /groups/{group_id}/ai/chat
{
  "model_name": "gpt-4",
  "messages": [
    {"role": "user", "content": "帮我查看当前目录下的文件列表"}
  ]
}

🖥️ 本地运行命令

环境准备

# 1. 确保 Python 3.12+
python --version

# 2. 安装依赖（推荐 uv）
cd kuai-service-py
uv sync

# 或使用 pip
pip install -e .

启动服务

# 方式一：使用 uv（推荐）
uv run python main.py

# 方式二：直接 python
python main.py

# 方式三：使用 uvicorn 命令（支持热重载）
uvicorn src.api:create_app --factory --reload --host 0.0.0.0 --port 8000

启动后验证

# 健康检查
curl http://localhost:8000/healthz
# → {"status": "OK", "issues": []}

# 查看 API 文档
open http://localhost:8000/docs       # Swagger UI
open http://localhost:8000/redoc      # ReDoc

# 查看服务器列表
curl http://localhost:8000/servers/

环境变量

变量名默认值说明
KUAI_SKIP_MCP_AUTOSTARTfalse设为 true 跳过启动时自动连接 MCP 服务器
KUAI_MCP_AUTOSTART_TIMEOUT120自动启动超时时间（秒）
KUAI_MCP_AUTOSTART_RETRIES2自动启动重试次数

🐛 调试技巧

📋 日志排查

应用日志输出到 logs/kuai-mcp.log 和 stdout。日志级别通过 log_config.yaml 配置。启动失败时先看日志中的 ERROR 级别信息。

🔍 健康检查

每个服务器都有独立的健康检查端点：GET /servers/{name}/health。返回 ping 结果和连接状态。诊断端点 GET /servers/{name}/diagnostics 提供更详细的 transport 信息。

🧪 跳过自动启动

开发调试时可以设置 KUAI_SKIP_MCP_AUTOSTART=true 环境变量，跳过启动时自动连接所有服务器，手动逐个启动需要调试的服务器。

📊 Swagger UI

访问 http://localhost:8000/docs 可以直接在浏览器中测试所有 API 端点，查看请求/响应模型，是最快的接口调试方式。

🔧 工具调用测试

先通过 GET /servers/{name} 确认服务器已连接且有工具。然后用 POST /tools/servers/{name}/{tool}/call 直接调用测试。分组工具可通过 MCP SSE 端点测试。

⚠️ 常见问题排查

连接超时：检查 url 是否正确、网络是否可达。
工具为空：服务器连接成功但未返回工具，检查 MCP 服务器端实现。
Stdio 失败：检查 command 和 args 是否正确，env 中的变量是否已设置。

常用调试命令速查

# 查看所有服务器状态（快速概览）
curl -s http://localhost:8000/servers/ | python -m json.tool

# 启动特定服务器
curl -X POST http://localhost:8000/servers/my-server/start

# 查看服务器诊断信息（包括连接次数、失败次数等）
curl http://localhost:8000/servers/my-server/diagnostics

# 调用工具
curl -X POST http://localhost:8000/tools/servers/my-server/tool_name/call \
  -H "Content-Type: application/json" \
  -d '{"arguments": {"param1": "value1"}}'

# 获取分组可用工具
curl http://localhost:8000/groups/{group_id}/tools

# 重启服务器（连接异常时）
curl -X POST http://localhost:8000/servers/my-server/restart
