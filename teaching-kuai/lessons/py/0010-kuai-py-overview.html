🐍 kuai-service-py 项目概览

概览 了解 MCP 服务器管理平台的定位、技术栈、目录结构和核心功能

🎯 项目定位

kuai-service-py 是 KuAI 测试平台的 Python MCP 服务，它的核心职责是充当一个 MCP（Model Context Protocol）服务器管理平台。

一句话概括

一个基于 FastAPI 的服务，支持 SSE / Stdio / StreamableHTTP 三种传输协议，通过统一的 HTTP 接口管理和访问多个 MCP 服务器，让 AI Agent 能以标准化方式调用各类工具。

它在整个 KuAI 平台中扮演的角色是 "工具层"——前端的 Agent 通过分组接口获取 MCP 工具列表，调用工具时由本服务路由到对应的 MCP 服务器执行。

🛠️ 技术栈

层级技术说明
Web 框架FastAPI异步高性能 Web 框架，提供 RESTful API 和 OpenAPI 文档
MCP SDKmcp (官方 Python SDK)提供 ClientSession、SSE/Stdio/StreamableHTTP 客户端
ASGI 服务器Uvicorn生产级 ASGI 服务器，运行 FastAPI 应用
数据模型Pydantic数据验证和序列化（ServerConfig、GroupConfig 等）
数据库数据库持久化通过 ServerRepository / GroupRepository 存储配置
AI 集成LangChain + langgraph智能路由（SmartRouter）、分组 MCP 服务器中的 AI Agent 对话
向量存储ChromaDB / 内存存储工具向量嵌入，支持语义搜索路由
依赖管理uvPython 3.12+，推荐 uv 管理依赖

🧩 核心功能

🔌 多协议支持

支持 SSE（HTTP 单向推送）、Stdio（本地进程标准 IO）、StreamableHTTP（HTTP 流式双向通信）和 Agent 四种传输协议。通过 TransportFactory 工厂模式统一创建。

🖥️ 服务器管理

支持动态添加、删除、配置 MCP 服务器。支持启动/停止/重启操作，自动重试和超时控制。启动时自动加载工具列表，后台并行启动 auto_start 服务器。

📂 分组管理

将多个 MCP 服务器组织成逻辑分组，支持分组级别的工具访问控制（指定 "all" 或具体工具列表），每个分组可暴露为一个独立的 MCP Server 端点。

🤖 智能路由

SmartRouter 基于向量嵌入实现语义搜索路由，AI Agent 可用自然语言描述需求，自动匹配最合适的工具。支持语义搜索、精确匹配、模糊匹配三种策略。

🌐 统一 HTTP 接口

RESTful API 设计，自动生成 OpenAPI 文档。提供服务器 CRUD、分组 CRUD、工具调用、健康检查等端点。每个分组还可通过 /groups/{id}/mcp 暴露 MCP SSE 端点。

🔄 会话池管理

TransportSessionPool 管理 MCP 连接的会话生命周期，避免频繁创建/销毁连接。Keep-alive 机制自动维持 SSE 和 StreamableHTTP 连接。
