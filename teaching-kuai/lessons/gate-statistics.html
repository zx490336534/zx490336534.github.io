发布门槛：硬失败、样本量和统计不确定性

把严重规则违规、样本不足和一般质量下降分成不同发布结果。

先看场景

两次评测都零失败：一次跑了 5 个样本，另一次跑了 100 个。两者的保证一样强吗？

置信区间：在抽样模型成立时，用数据给未知比例提供一个带不确定性的范围，而不是把观察比例当真值。

可复制到 lesson.py，再运行 python3 lesson.py。

from math import sqrt

def lower_bound(passed, total, z=1.96):
    if not 0 <= passed <= total or total <= 0:
        raise ValueError("invalid counts")
    rate = passed / total
    center = rate + z*z / (2*total)
    radius = z * sqrt(rate*(1-rate)/total + z*z/(4*total*total))
    return (center - radius) / (1 + z*z/total)

def gate(passed, total, hard_fail, evidence_missing):
    if hard_fail:
        return "blocked"
    if evidence_missing or total < 30:
        return "review"
    if lower_bound(passed, total) < 0.90:
        return "review"
    return "pass"

assert lower_bound(5, 5) < lower_bound(100, 100)
assert gate(5, 5, False, False) == "review"
assert gate(100, 100, False, False) == "pass"
assert gate(100, 100, True, False) == "blocked"
assert gate(100, 100, False, True) == "review"

发布有硬门槛和证据门槛

越权写入是硬失败，一次也阻断；大样本均分抵消不了。普通用例可以看通过率的 Wilson 区间。在相同样本上比较候选与基线时宜看配对差异而不是把两个比例当作独立。

解释下界的条件

示例用 z=1.96 计算近似双侧 95% Wilson 区间下界。独立样本且分布具代表性才适用；同源样本和重复运行会扩大不确定性，不可重复计入样本量来缩小区间。

状态要允许‘证据不够’

如果没有发现硬违规，但没有达到最小样本量或区间下界目标，进入复核而不是自动发布。对罕见但严重的风险要做定向测试，采样没发现不代表它为零。

复现失败

样本数不足
怎么触发：5 条全部通过，关键项均有证据。
怎么判断：复核，不把小样本 100% 当成强保证。
关键轨迹缺证据
怎么触发：普通准确率正常，但一条关键用例无轨迹。
怎么判断：复核或按产品策略阻断；不能算安全通过。

写下这些测试断言

  • 硬失败优先于统计量。
  • 无样本不能算 100%。
  • 相关变体不会人造放大有效样本量。
  • 报告样本量、区间条件和欠覆盖分层。

这一课带走：高置信不是高分的同义词。放行决策要说清楚样本来源、结果与剩余不确定性。
