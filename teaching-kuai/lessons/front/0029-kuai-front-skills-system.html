Lesson 29: 技能系统（Skills）详解

渐进式披露机制、SKILL.md 格式、skillLoader、getSkillTools 与技能目录结构

前置知识

学习本课前，建议先了解以下概念：

  • LangChain 基础 — 了解 Agent 和 Tool 的基本概念
  • Agent 系统架构 — 了解 Agent 系统整体架构

1. 为什么需要技能系统？

想象一个 AI Agent 是一个"全栈工程师"。他什么都会一点，但不可能把所有知识都装在脑子里。

技能系统的设计理念就像给工程师一本工具手册：

类比理解
  • Agent 的系统提示 = 工程师脑子里记住的东西（有限）
  • 技能系统 = 书架上的工具手册（按需翻阅）
  • list_skills = 看看书架上有哪些手册
  • get_skill_content = 翻开某本手册，阅读具体内容

如果把所有技能的详细内容都塞进系统提示词，会消耗大量 Token，而且 Agent 大部分时候用不到它们。渐进式披露解决了这个问题。

2. 渐进式披露机制

"渐进式披露"（Progressive Disclosure）的核心思想：先告诉你有什么，需要时再给细节。

2.1 三步交互流程

第一步：系统提示词只包含技能列表（名称 + 简短描述）
系统提示: "你有以下技能可用：git-clone（克隆仓库）、dev-design（技术设计文档）..."

第二步：Agent 调用 list_skills 查看所有技能详情
Agent → list_skills() → 返回所有技能的名称和描述

第三步：Agent 根据需要调用 get_skill_content 读取具体技能文档
Agent → get_skill_content("dev-design") → 返回 SKILL.md 的完整内容
为什么要这样做？
方式Token 消耗效果
全部塞进系统提示很高（浪费）Agent 可能忽略大部分内容
渐进式披露很低（按需）Agent 只在需要时加载，更精准

3. SKILL.md 文件格式

每个技能的核心是一个 SKILL.md 文件，它必须包含 YAML frontmatter（文件开头的 --- 之间的部分）。

3.1 文件结构

文件路径: src/agents/skills/my-skill/SKILL.md

---
name: my-skill
description: 简短描述技能功能（1-2句话）
---

# 技能标题

## 核心功能
这个技能能做什么...

## 快速开始
最简单的使用示例...

## 工作流程
典型使用流程（步骤化）...

## 工具参数
详细说明每个工具的参数...

## 最佳实践
使用建议和注意事项...

## 常见场景
各种使用场景的示例...

3.2 Frontmatter 字段说明

必须遵守的规则
字段必填说明
name是技能名称，使用 kebab-case（如 git-clone）
description是简短描述（1-2句），会出现在系统提示中
命名规范
  • ✅ git-clone、dev-design、test-analysis（kebab-case）
  • ❌ gitClone、GitClone、git_clone（不要用驼峰、大写或下划线）

4. 技能目录结构

所有技能都放在 src/agents/skills/ 目录下，每个技能一个子目录：

src/agents/skills/
├── git-clone/                  # Git 仓库克隆
│   ├── SKILL.md               # 技能定义文件（必须）
│   └── references/            # 参考资料（可选）
│       ├── best-practices.md
│       └── examples.md
│
├── dev-design/                 # 技术设计文档
│   ├── SKILL.md
│   └── references/
│
├── test-analysis/              # 测试分析报告
│   ├── SKILL.md
│   └── references/
│
├── mermaid/                    # Mermaid 图表
├── drawio-diagrams-enhanced/   # Draw.io 图表
├── env-issue-resolver/         # 环境问题排查
├── code-explore/               # 代码探索分析
├── dcs-drawing-helper/         # DCS 图纸辅助
├── test-case-formatter/        # 测试用例格式化
├── ui-localization/            # UI 本地化翻译
├── apollo-ai-case/             # Apollo AI 用例生成
└── langfuse/                   # Langfuse 可观测性
目录规则
  • SKILL.md — 必须，包含 YAML frontmatter 和技能内容
  • references/ — 可选，存放参考资料（best-practices.md、examples.md 等）
  • 目录名 = 技能名，使用 kebab-case

5. 技能加载器（skillLoader）

skillLoader.js 是技能系统的"发动机"，负责扫描技能目录、读取文件、创建工具。

核心代码在 src/agents/tools/skillLoader.js：

// skillLoader.js 的核心逻辑（简化版）

export async function getSkillTools({ skills } = {}) {
  const skillsDir = path.join(process.cwd(), 'src/agents/skills');

  // 1. 扫描技能目录
  let skillDirs = [];
  if (skills && skills.length > 0) {
    // 指定了技能列表 → 只加载指定的
    skillDirs = skills;
  } else {
    // 没指定 → 自动扫描整个 skills/ 目录
    skillDirs = fs.readdirSync(skillsDir);
  }

  // 2. 读取每个技能的 SKILL.md frontmatter
  const skillList = skillDirs.map(name => {
    const content = fs.readFileSync(
      path.join(skillsDir, name, 'SKILL.md'), 'utf-8'
    );
    const { data } = matter(content); // 解析 YAML frontmatter
    return { name: data.name, description: data.description };
  });

  // 3. 创建两个 LangChain 工具
  return [
    // list_skills 工具：列出所有可用技能
    tool(async () => JSON.stringify(skillList), {
      name: 'list_skills',
      description: '列出所有可用的技能',
    }),

    // get_skill_content 工具：读取指定技能的完整内容
    tool(async ({ skillName }) => {
      const filePath = path.join(skillsDir, skillName, 'SKILL.md');
      // 路径安全检查：防止读取技能目录之外的文件
      return fs.readFileSync(filePath, 'utf-8');
    }, {
      name: 'get_skill_content',
      description: '获取指定技能的详细内容',
      schema: z.object({ skillName: z.string() }),
    }),
  ];
}

5.1 加载方式对比

两种加载方式
方式代码说明
指定技能getSkillTools({ skills: ['git-clone', 'dev-design'] })只加载指定的技能
自动扫描getSkillTools()自动扫描 skills/ 目录下所有技能

6. 在 Agent 中使用 getSkillTools

在 Agent 的 createAgent 函数中加载技能：

import { defineAgent } from '@/lib/agents/define';
import { createReactAgent } from '@langchain/langgraph/prebuilt';
import { getGitCloneTools, getSkillTools, getMCPTools } from '@/agents/tools';

export default defineAgent({
  name: '代码助手',
  description: '帮助分析代码并生成文档',

  createAgent: async () => {
    // 并行加载所有工具（提高启动速度）
    const [gitTools, mcpTools, skillTools] = await Promise.all([
      getGitCloneTools(),
      getMCPTools(MCP_SERVERS, { useCache: true }),
      // 指定这个 Agent 需要哪些技能
      getSkillTools({
        skills: ['git-clone', 'dev-design', 'test-analysis']
      }),
    ]);

    return createReactAgent({
      llm: model,
      tools: [...gitTools, ...mcpTools, ...skillTools],
    });
  },
});
技能依赖提醒

使用 dev-design 或 test-analysis 技能时，通常需要同步接入 confluence-mcp，以提供 Confluence 读取和发布能力。否则技能的文档发布功能将无法使用。

7. 如何新建一个技能（实战步骤）

五步创建新技能
  1. 在 src/agents/skills/ 下创建新目录（如 my-skill/）
  2. 创建 SKILL.md 文件，写入 YAML frontmatter + 内容
  3. 可选：创建 references/ 子目录，添加参考资料
  4. 在 Agent 中使用 getSkillTools({ skills: ['my-skill'] })
  5. 测试：在对话中尝试让 Agent 使用你的技能
# 步骤 1: 创建目录
mkdir src/agents/skills/my-skill

# 步骤 2: 创建 SKILL.md
cat > src/agents/skills/my-skill/SKILL.md << 'EOF'
---
name: my-skill
description: 我的自定义技能，用于xxx场景
---

# 我的技能

## 核心功能
这个技能用来...

## 快速开始
1. 第一步...
2. 第二步...
EOF
