Python 示例 可折叠

可复制到 lesson.py，再运行 python3 lesson.py。

from collections import deque

def replay(records):
    pending = deque(records)
    def lookup(slot):
        if not pending:
            raise AssertionError("unexpected extra call")
        requested, seats = pending.popleft()
        assert slot == requested
        return seats
    return lookup, pending

def may_book(now, expires, lookup):
    if now >= expires:
        return False
    return lookup("slot-b") > 0

lookup, pending = replay([("slot-b", 1)])
assert may_book(119, 120, lookup)
assert not pending

lookup, pending = replay([])
assert not may_book(120, 120, lookup)
assert not pending

边界直接驱动

把当前时间变成参数，写出 expires-1 与 expires 两个场景。不需要 sleep。示例中到期时间点本身视为无效，和 UI 显示精度无关。

重放不等于允许任何调用

重放器验证调用槽位、次数和顺序。缺记录时不返回假成功；调用结束后也检查没有剩余响应。这能抓住多做一次、少做一次或换错参数。

合成数据不带历史包袱

夹具每次从干净状态构造，不用共享可变列表。若要检查真实适配器格式，可运行合约烟测，但不要指望内存重放覆盖网络异常或时区转换。

复现失败

边界错一秒
怎么触发：把到期判断改成 now > expires。
怎么判断：恰好到期会意外查座位，重放器拒绝额外调用。
参数串了
怎么触发：把查询换成 slot-x。
怎么判断：记录中的下一步与请求不匹配，测试失败。

写下这些测试断言

  • 同一夹具反复重放得到相同结果。
  • 运行时钟和测试时钟使用同一个业务入口。
  • 过期时不发外部请求。
  • 夹具使用后检查无未消费记录。

这一课带走：稳定复现比盲目重跑更有价值。固定外部变量，也要检查实际依赖调用是否仍符合约定。
