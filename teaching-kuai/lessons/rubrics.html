评分标准与人工校准：从主观意见变成可复核证据

把清晰、正确与关键风险拆成维度，通过双人盲评调整标准。

先看场景

两位评审都说「有点不清楚」，但一人只有格式意见，另一人发现答复根本没有给出需要确认的下一步。

评分锚点：用具体正反例说明某一档分数对应的可观察行为，让两个评审知道在对齐什么。

走一遍

  1. 把正确性和行动可读性拆开。
  2. 写档位锚点和可引用证据。
  3. 两人独立评分，保留原值和分歧项。
合成示例 可折叠
DIMENSIONS = ("correctness", "next_step")

第二遍 · 把代码读懂

代码拆解

两个评审对是否可操作意见相反，只看总体平均分可以吗？

调用链

  1. 把正确性和行动可读性拆开。
  2. 写档位锚点和可引用证据。
  3. 两人独立评分，保留原值和分歧项。
  4. 通过讨论更新标准版本，再做一次新的校准。
Python 示例 可折叠

可复制到 lesson.py，再运行 python3 lesson.py。

DIMENSIONS = ("correctness", "next_step")
left = {
    "u1": {"correctness": 2, "next_step": 1},
    "u2": {"correctness": 0, "next_step": 0},
}
right = {
    "u1": {"correctness": 2, "next_step": 2},
    "u2": {"correctness": 0, "next_step": 0},
}

def calibrate(a, b):
    if set(a) != set(b):
        raise ValueError("reviewers must score the same samples")
    disagreements = []
    for sample in sorted(a):
        for dim in DIMENSIONS:
            x, y = a[sample][dim], b[sample][dim]
            if x not in {0, 1, 2} or y not in {0, 1, 2}:
                raise ValueError("unknown score")
            if x != y:
                disagreements.append((sample, dim, x, y))
    return disagreements

assert calibrate(left, right) == [("u1", "next_step", 1, 2)]
assert calibrate(left, left) == []

定义可观察档位

对 CaseLab 的确认回答，正确性要判断有无声称已预约，可操作性要判断用户是否知道确认哪个槽位。每项有 0、1、2 三个档位，新样本由两个评审各自看文本和同一证据。

盲评后追问同一条证据

示例按样本与维度列出分歧，绝不平均成一个值。U1 的行动指示可看具体呈现；先复核是不是标准模糊，还是某位评审遗漏证据，再记录裁决；原始标注保留。

简单一致率不是质量证明

两个评审可能一致地理解错规则，稀有高风险类别也会被大量一致的简单样本淹没。把关键项单独抽样，标准改动单独发版本；高影响分歧需要仲裁后再进入金标集。

复现失败

只看总体
怎么触发：u1 在下一步动作上分歧，正确性相同。
怎么判断：分歧定位到 u1/next_step，而非被正确性平均掉。
两人评了不同题
怎么触发：去掉一位评审的 u2。
怎么判断：显式拒绝比较，防止看起来一致。

写下这些测试断言

  • 样本与维度都对齐。
  • 不存在悄悄丢掉的分歧。
  • 复核可引用答复里的文本或动作证据。
  • 更新锚点后记录规则版本。

这一课带走：校准不是让两人分数看起来一样，而是弄清一分差对应哪段可观察的证据。
