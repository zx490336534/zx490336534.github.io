UI 自动化框架搭建

从管理定位元素开始，搭出能运行、能出报告的自动化测试框架。

20 篇

适合 想把零散的 UI 测试脚本组织成框架的读者

读第一篇 · 用 YAML 管理 UI 元素定位规则 ↗
框架与首个脚本执行流程与测试报告图像定位与素材采集失败诊断与性能采集

框架与首个脚本

  1. 用 YAML 管理 UI 元素定位规则
  2. 用 Selenium 查找元素并高亮定位结果
  3. 封装 Selenium 元素操作基类：查找、等待与 Allure 记录
  4. 组织 UI 自动化项目并封装浏览器启动
  5. 封装测试日志、时间与随机数据
  6. 组合 Allure 装饰器并添加报告附件
  7. 用 pytest 钩子在测试失败时自动截图
  8. 用 pytest 编写第一个 H5 UI 自动化用例

执行流程与测试报告

  1. 用 Jenkinsfile 执行 UI 测试并生成 Allure 报告
  2. 在 Python 测试脚本中读取 Jenkins 构建参数
  3. 编写 pytest 命令行入口：选择用例、并发运行与生成报告
  4. 用 Sonic 和 uiautomator2 编写 App 自动化用例
  5. 解析 Allure 结果：提取用例状态、参数与异常
  6. 用企业微信推送 UI 测试结果和 Allure 报告链接

图像定位与素材采集

  1. 读懂 Airtest 的 Template 图像匹配流程
  2. 把 Airtest 图像匹配接入 UI 自动化框架
  3. 用 Sonic 获取图像定位素材

失败诊断与性能采集

  1. 在企业微信通知里附上失败步骤、异常和截图
  2. 用 mobileperf 采集 App 自动化测试的 CPU、帧率和内存
  3. 按性能阈值标记表现较差的 Allure 用例
