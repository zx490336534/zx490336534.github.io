在进行Web UI的自动化测试的时候，有些错误无法简单的通过文字描述清楚，还是需要进行页面截图。但为了让该优化不需要投入过多的时间，采用装饰器进行装饰。

基本思路：正常执行脚本，当异常或断言报错时，触发截图，正常返回异常

编写装饰器

大概装饰器代码如下

  1. def error_screenshot(func):
  2.     @wraps(func)
  3.     def decorator(*args, **kwargs):
  4.         try:
  5.             obj = func(*args, **kwargs)
  6.         except Exception as e:
  7.             截图操作
  8.             raise Exception(e)
  9.         return obj
  11.     return decorator

使用 tryexcept可以捕获到异常，使用 raiseException(e)完成截图后把异常继续抛出。

因为每次的 driver对象所处的 类名可能不一致，所以进行一定的判断。假设进行界面操作的类名都是以 ui结尾。

  1. for key, value in locals()['kwargs'].items():
  2.     if key.endswith('ui'):
  3.         pic_name = f'{str(time.time())}.png'
  4.         value.driver.save_screenshot(pic_name)
  5.         allure.attach.file(f'{pic_name}', attachment_type=allure.attachment_type.PNG)

循环当前的 locals()['kwargs']拿到该类名，再使用该类中的 driver对象进行截图操作，并使用 allure将图片显示在报告中。

编写操作类

本次测试将 百度当做测试目标

简单的封装一个操作百度的界面操作类：BaiDuActionUi

包含了：

  • 打开百度 open_web

  • 在输入栏输入指定内容 input_message

  • 在定位错误的输入栏输入指定内容 input_message_bug

  • 点击查找按钮 search

  • 关闭浏览器 close

  1. class BaiDuActionUi():
  2.     def __init__(self):
  3.         self.url = 'https://www.baidu.com'
  4.         self.driver = webdriver.Chrome(executable_path='./chromedriver')
  5.         self.driver.implicitly_wait(3)
  6.         self.input = 'kw'  # 搜索栏
  7.         self.search_btn = 'su'  # 查找按钮
  9.     def __str__(self):
  10.         return '百度'
  12.     @allure.step('打开页面')
  13.     def open_web(self):
  14.         self.driver.get(self.url)
  16.     @allure.step('输入内容')
  17.     def input_message(self, message):
  18.         self.driver.find_element_by_id(self.input).clear()
  19.         self.driver.find_element_by_id(self.input).send_keys(message)
  21.     @allure.step('有异常的输入内容')
  22.     def input_message_bug(self, message):
  23.         self.driver.find_element_by_id(f'{self.input}1').clear()
  24.         self.driver.find_element_by_id(f'{self.input}1').send_keys(message)
  26.     @allure.step('点击查找')
  27.     def search(self):
  28.         self.driver.find_element_by_id(self.search_btn).click()
  30.     @allure.step('关闭浏览器')
  31.     def close(self):
  32.         try:
  33.             self.driver.close()
  34.         except Exception as e:
  35.             print(f'关闭浏览器失败:{e}')

编写测试代码

使用 fixture编写测试前浏览器的开启，测试后浏览器的关闭

  • 正常测试： test_selenium

  • 抛出断言错误的测试： test_selenium1

  • 定位异常的测试： test_selenium2

  1. @pytest.fixture()
  2. def baiduactionui():
  3.     baidu = BaiDuActionUi()
  4.     baidu.open_web()
  5.     yield baidu
  6.     baidu.close()

  12.     正常

  15.         baiduactionui.input_message('python')
  16.         baiduactionui.search()
  19. @error_screenshot
  20. def test_selenium1(baiduactionui):
  21.     """
  22.     assert 异常
  23.     """
  24.     with allure.step(f'测试输入python点击查找'):
  25.         baiduactionui.input_message('python')
  26.         baiduactionui.search()
  27.         assert 0, '瞎报的异常'
  30. @error_screenshot
  31. def test_selenium2(baiduactionui):
  32.     """
  33.     driver 查找元素异常
  34.     """
  35.     with allure.step(f'测试输入python点击查找'):
  36.         baiduactionui.input_message_bug('python')

  40. if __name__ == '__main__':
