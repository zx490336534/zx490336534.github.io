安装

npm install -g @qwen-code/qwen-code

配置

export OPENAI_API_KEY="sk-你的key"
export OPENAI_BASE_URL="你的大模型地址"
export OPENAI_MODEL="qwen3-coder-plus"

接入MCP

https://github.com/QwenLM/qwen-code/blob/main/docs/cli/tutorials.md

在项目路径下新建 .qwen/settings.json

以StreamableHTTPClientTransport类型MCP为例

{
    "mcpServers": {
        "tools": {
            "httpUrl": "http://saas-help-mcp-dev.k8s-qunhe.qunhequnhe.com/tools-mcp",
            "timeout": 30000,
            "trust": false
        }
    }
}

其他更多配置参考：https://gemini-doc.haleclipse.de/zh/tools/mcp-server.html

qwen3-coder-plus计费说明：按照阶梯计费，输入越多，价格越贵

简单计算一下本次消耗

  1. 确定价格阶梯:

    • 输入 Token 数为 257,519，超过了 256,000 (256K)，因此属于 256K～1M 这个价格区间。
    • 根据该区间，输入价格为 0.01元/千Token，输出价格为 0.1元/千Token。

  2. 计算输入费用:

    • 输入费用 = (输入 Token 数 / 1000) * 输入单价
    • 输入费用 = (257,519 / 1000) * 0.01 = 257.519 * 0.01 = 2.57519 元

  3. 计算输出费用:

    • 输出费用 = (输出 Token 数 / 1000) * 输出单价
    • 输出费用 = (8,301 / 1000) * 0.1 = 8.301 * 0.1 = 0.8301 元

  4. 计算总费用:

    • 总费用 = 输入费用 + 输出费用
    • 总费用 = 2.57519 + 0.8301 = 3.40529 元

本次 qwen3-coder-plus 模型调用的总消耗金额为 3.40529 元。
