背景

下图是RAG的整个流程：


经过实践，发现直接将完整的文档导入的知识库后，回答的效果不是很好。
因为问答其实是将用户的提问向量化后，再在向量知识库中查找「被搜索的内容」，然后将内容填充到大模型的上下文中，给出
但是大部分的文档中标题可能无法完整的描述文中的内容，也就是在向量查询的时候大概率无法命中正确的内容。
如果人工将内容进行分割可以显著提高回答的质量，但是这样的话人力成本会比较大。
所以我们借助spaCy增强数据粒度：修订和简化数据内容，确保正确性和可读性；删除不相关信息，消除歧义，确认事实准确性，维护上下文连贯性

spaCy介绍

spaCy 是一个高性能的自然语言处理（NLP）库，广泛应用于实业界和学术界，提供了多种语言的支持和许多强大的语言处理功能。
spaCy 的设计重点在于速度和效率，在处理大规模文本数据时尤其出色。
其托管的中文模型 zh_core_web_lg 可以用于执行多种自然语言处理任务，如：

  • 分词（Tokenization）
    ：将文本分割成单独的词汇或标记。
  • 词性标注（POS Tagging）
    ：标记每个词汇的词性（如名词、动词等）。
  • 命名实体识别（NER）
    ：识别文本中的特定实体（如人名、地点、组织）。
  • 依存句法分析（Dependency Parsing）
    ：分析词汇之间的依存关系，帮助理解句子结构。

spaCy核心特性

  1. 高效处理
     
  • 基于Cython实现，处理速度显著优于纯Python库（如NLTK）。
  • 单管道处理文本，避免冗余计算。
  1. 预训练模型与多语言支持
      
  • 提供多种语言的预训练模型（如英语en_core_web_sm、中文zh_core_web_sm），支持分词、词性标注等任务。
  • 支持超过60种语言的基础处理。
  1. 深度学习集成
      
  • 整合Transformer模型（如通过spacy-transformers库），支持BERT等架构。
  • 自定义神经网络组件（如文本分类器）可通过PyTorch/TensorFlow扩展。
  1. 模块化管道（Pipeline）
      
  • 允许用户自定义处理流程，灵活添加/移除组件（如分词器、实体识别器）。
  • 支持添加自定义管道组件，集成外部算法。

spaCy安装

Spacy官方:https://spacy.io/

pip install spacy

zh_core_web_lg模型下载
https://spacy.io/models/zh

python -m spacy download zh_core_web_lg

测试一下

import spacy  

# 加载预训练的中文模型  
nlp = spacy.load('zh_core_web_lg')  

# 处理一段中文文本  
text = "这是一个测试句子。"  
doc = nlp(text)  

# 输出处理结果  
for token in doc:  
    print(token.text, token.pos_, token.dep_)

spaCy核心功能

分词（Tokenization）

智能分割文本为单词或标点，支持非空格语言（如中文）

  import spacy
  nlp = spacy.load("en_core_web_sm")
  doc = nlp("Apple is looking at buying U.K. startup for $1 billion.")
  print([token.text for token in doc])  

词性标注（POS Tagging）与依存分析

识别单词的语法角色及句子结构关系

  for token in doc:
      print(f"{token.text}: {token.pos_}, {token.dep_}")

命名实体识别（NER）

检测人名、组织、地点、日期等实体

  for ent in doc.ents:
      print(f"{ent.text} - {ent.label_}")

词向量与相似度计算

基于预训练模型计算词语相似度

  print(doc[0].vector)          # 获取词向量
  print(token.similarity(doc[2]))  # 计算相似度

规则与匹配

  • Matcher
    ：基于词汇规则的高效模式匹配。
  • PhraseMatcher
    ：快速短语匹配（如关键词检索）。
  from spacy.matcher import Matcher
  matcher = Matcher(nlp.vocab)
  pattern = [{"LOWER": "iphone"}, {"IS_DIGIT": True, "OP": "?"}]
  matcher.add("IPHONE_PATTERN", [pattern])
  matches = matcher(doc)
