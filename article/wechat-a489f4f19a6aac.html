环境搭建

安装环境

$ pip install virtualenv
$ virtualenv my_env
$ source my_env/bin/activate
$ pip install Django==2.0.5

校验环境

>>> import django
>>> django.get_version()
'2.0.5'

创建项目

$ django-admin startproject mysite

数据库初始化

$ python manage.py migrate

运行Django

$ python manage.py runserver

结果查看

访问http://127.0.0.1:8000/查看运行结果
