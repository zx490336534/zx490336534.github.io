https://github.com/langchain-ai/langserve

LangServe 🦜🏓 帮助开发者将 LangChain 可运⾏和链部署为 REST API。
该库集成了 FastAPI 并使⽤ pydantic 进⾏数据验证。

特性

  • 从 LangChain 对象⾃动推断输⼊和输出模式，并在每次 API 调⽤中执⾏，提供丰富的错误信息
  • 带有 JSONSchema 和 Swagger 的 API ⽂档⻚⾯（插⼊示例链接） 
  • ⾼效的 /invoke 、 /batch 和 /stream 端点，⽀持单个服务器上的多个并发请求 
  • /stream_log 端点，⽤于流式传输链/代理的所有（或部分）中间步骤
  • 新功能 ⾃ 0.0.40 版本起，⽀持 /stream_events ，使流式传输更加简便，⽆需解析 /s tream_log 的输出。
  • 使⽤经过严格测试的开源 Python 库构建，如 FastAPI、Pydantic、uvloop 和 asyncio。
  • 使⽤客户端 SDK 调⽤ LangServe 服务器，就像本地运⾏可运⾏对象⼀样（或直接调⽤ HTTP API）

安装

安装包

conda create python=3.11 --name langserver
conda activate langserver

pip install --upgrade "langserve[all]"

pip install -U langchain-cli

创建应用

langchain app new myLangServer
% langchain app new myLangServer
What package would you like to add? (leave blank to skip): 


Success! Created a new LangChain app under "./myLangServer"!


Next, enter your new app directory by running:

    cd ./myLangServer

Then add templates with commands like:

    langchain app add extraction-openai-functions
    langchain app add git+ssh://git@github.com/efriis/simple-pirate.git

安装环境

pip install poetry

添加依赖

poetry add pydantic@^2.7.4
poetry add langchain 
poetry add langchain-openai

升级pydantic的原因：

% poetry add langchain

Using version ^0.3.23 for langchain

Updating dependencies
Resolving dependencies... (4.0s)

Because no versions of langchain match >0.3.23,<0.4.0
 and langchain (0.3.23) depends on pydantic (>=2.7.4,<3.0.0), langchain (>=0.3.23,<0.4.0) requires pydantic (>=2.7.4,<3.0.0).
So, because mylangserver depends on both pydantic (<2) and langchain (^0.3.23), version solving failed.

依赖添加之后 pyproject.toml 文件的 tool.poetry.dependencies 部分

[tool.poetry.dependencies]  
python = "^3.11"  
uvicorn = "^0.23.2"  
langserve = {extras = ["server"], version = ">=0.0.30"}  
pydantic = ">=2.7.4"  
langchain = "^0.3.23"  
langchain-openai = "^0.3.14"

另外由于fastapi中pydantic的相关问题需要修改它的版本
https://github.com/fastapi/fastapi/issues/10360

pip install -U fastapi==0.100.0

修改server.py

from fastapi import FastAPI  
from fastapi.responses import RedirectResponse  
from langchain_openai import ChatOpenAI  
from langserve import add_routes  

app = FastAPI()  


@app.get("/")  
async def redirect_root_to_docs():  
    return RedirectResponse("/docs")  


# Edit this to add the chain you want to add  
add_routes(app,  
           ChatOpenAI(  
               model="deepseek-chat",  
               api_key="sk-xxxx",  
               base_url="https://api.deepseek.com"  
           ),  
           path='/openai')  

if __name__ == "__main__":  
    import uvicorn  

    uvicorn.run(app, host="0.0.0.0", port=8000)

运行

poetry run langchain serve --port=8000
