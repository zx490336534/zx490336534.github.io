用快捷指令一键唤起我的 AI 管家

目标

我想在 iPhone 上一键和 Hermes 说话。按一下侧键，说完话，消息进飞书，后面就在飞书里继续聊。

理想状态很简单。侧键触发快捷指令，语音转文字，直接发给飞书里面的Hermes。

Hermes 是什么

Hermes 是我自己日常使用的 AI 管家。它接在飞书里，可以帮我写代码、查问题、整理 Obsidian 笔记、写会议纪要，也可以处理一些临时冒出来的工作问题。

这篇文档只解决入口问题。手机上用侧键，Mac 上用 Alfred，最后都落到飞书群里。

需求

  • • 我只想保留飞书这一个入口。手机侧键发起，消息进飞书，后面继续在飞书里聊。
  • • 使用场景主要在通勤和散步
  • • 这个入口也要能在 Mac 上用。临时想到一句话，直接从 Alfred 发给 Hermes。

最终方案 Webhook 自定义机器人 @ Hermes

在飞书群里加一个自定义机器人，拿到一条静态 webhook URL。iPhone 快捷指令、Alfred Workflow、curl 或脚本都可以往这条 URL POST 消息。

消息内容里带上 @Hermes。Hermes 收到其他机器人 @ 自己后，按普通群消息处理。

这条方案的好处是维护成本低。没有 OAuth 授权，没有 refresh_token 轮换，也没有 7 天不用就过期的问题。

原理

iPhone 快捷指令（或其他客户端）
   │  发送 一条 文本 消息（内容带 @Hermes）
   ▼
WebHook 自定义机器人（群里，静态 URL，无 token）
   ▼
飞书推送消息事件给 Hermes
   ▼
Hermes 收到「其他机器人 @ 我」→ 执行任务 → 群里回复

一次性配置（在飞书群里，约 1 分钟）

  1. 1. 打开聊天群 → 设置 → 群机器人 → 添加机器人 → 自定义机器人
  2. 2. 命名（如「远程触发」），复制 Webhook 地址（https://open.feishu.cn/open-apis/bot/v2/hook/<xxx>）
  3. 3. 安全设置建议加自定义关键词。可以选一个平时经常带的词，比如「帮我」。这样 URL 泄露后也不容易被乱刷。

触发格式

POST 到 webhook URL，请求体如下。

{
  "msg_type": "text",
  "content": {
    "text": "<at user_id=\"ou_76b2388f33eede44d656d6b067105885\"></at> 帮我查一下今天的天气"
  }
}

<at user_id="ou_76b2388f33eede44d656d6b067105885"> 就是 @ Hermes，对应 Agent bot 的 open_id。

这段 @ 必须带上。否则会被 FEISHU_ALLOW_BOTS=mentions 忽略。

命令行可以这样测。

curl -X POST "https://open.feishu.cn/open-apis/bot/v2/hook/<你的hook>" \
  -H "Content-Type: application/json" \
  -d '{"msg_type":"text","content":{"text":"<at user_id=\"ou_76b2388f33eede44d656d6b067105885\"></at> 测试：收到请回复"}}'

iPhone 快捷指令

  1. 1. 听写文本（语音输入）
  2. 2. 替换文本。把换行替换为空，清掉听写里的 \n
  3. 3. 获取 URL 内容。方法选 POST，URL 填 webhook 地址。请求体 JSON 用「文本」变量拼出 {"msg_type":"text","content":{"text":"<at user_id=\"ou_76b2388f33eede44d656d6b067105885\"></at> <听写文本>"}}
  4. 4. 显示通知（可选）

绑定侧键 = 「侧键 → 说话 → 消息进群并 @Hermes → 回复出现在群里」。

Mac Alfred Workflow（桌面快速触发）

同一条 webhook 也可以放进 Alfred Workflow，作为 Mac 侧的轻量入口。

Alfred 输入 fs，选择二级场景后，Workflow 把拼好的文本 POST 到飞书自定义机器人。发送完成后，自动打开 Lark。

当前二级命令如下。

命令
用途
行为
h
会议纪要
整理成会议纪要，并在提示词中要求写入 /会议纪要/
c
剪贴板
直接发送剪贴板原文，不追加提示词
s
总结
总结内容，并在提示词中要求写入 Obsidian 笔记
t
待办
提取待办，并在提示词中要求写入 Obsidian 笔记

用法示例。

fs h <会议原文>
fs s <需要总结的内容>
fs t <讨论记录>
fs c

h/s/t 后不输入正文时，会读取剪贴板内容。复制一大段会议记录后，直接输入 fs h 就能发。

fs 空回车不会发送。它会先进入二级场景选择，避免误触发空消息。

取舍

  • • 没有 OAuth，也没有 refresh_token 轮换。
  • • 快捷指令里不用放 client secret。
  • • curl、快捷指令、脚本和其他设备都能触发。
  • • webhook URL 相当于群里的发言入口，不能外发。安全设置里最好加自定义关键词。
  • • 触发消息显示为自定义机器人发出。Hermes 回复仍然是 Agent bot 身份。

常见问题

  • • Hermes 没回复时，先看消息里有没有 @Hermes。FEISHU_ALLOW_BOTS=mentions 开启后，不带 @ 的机器人消息会被忽略。
  • • 快捷指令发送失败时，先检查 JSON 是否合法。听写内容里有换行时，先用「替换文本」清掉。
  • • webhook URL 相当于群里的发言入口，不能外发。飞书自定义机器人里建议加关键词校验。
