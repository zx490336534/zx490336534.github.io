ORM

对象关系映射

（英语：(Object Relational Mapping，简称ORM，或O/RM，或O/R mapping），是一种程序技术，用于实现面向对象编程语言里不同类型系统的数据之间的转换。从效果上说，它其实是创建了一个可在编程语言里使用的--“虚拟对象数据库”。
如下图可以看出，如果后台直接访问数据库的话，使用不同的数据库的话，每次的SQL语句都需要重写


但是如果使用ORM隔断后访问数据库的话，只需要维护一份数据库语句即可操作不同的数据库了。
通过ORM可以不用关心后台用的是哪种数据库，只需要按照ORM所提供的语法规则去书写相应的代码，ORM就会自动转换成对应数据库的 SQL 语句

创建表

创建Module的Base类

对象关系型映射，数据库中的表与python中的类相对应，创建的类必须继承自sqlalchemy中的基类。
使用declarative方法定义的映射类依据一个基类，这个基类是维系类和数据表关系的目录。
使用declarative_base创建一个基类

from sqlalchemy.ext.declarative import declarative_base
Base = declarative_base(engin)

创建Module的类

from datetime import datetime
from sqlalchemy import Column, Integer, String, DateTime, Boolean
from connect import Base
# Column：用来创建表中的一个字段的一个方法
# Integer：整形，映射到数据库中的int方法
# String:字符类型，映射到数据中的varchar类型，使用时需要提供长度
# DateTime:时间类型
class User(Base):
    __tablename__ = 'user'  # 数据库中的表名
    id = Column(Integer, primary_key=True, autoincrement=True)
    username = Column(String(20), nullable=False)
    password = Column(String(50))
    creatime = Column(DateTime, default=datetime.now)
    _locked = Column(Boolean, default=False, nullable=False)
    def __repr__(self):
        return """
            <User(id:%s, username:%s, password:%s, creatime:%s, _locked:%s)>
        """ % (self.id, self.username, self.password, self.creatime, self._locked)

创建表

if __name__ == '__main__':
    Base.metadata.create_all()  # 创建表需要执行这行代码，如果表存在则不创建

增删改查

在对表数据进行增删改查之前需要先建立会话，建立会话后才能操作。

创建会话

from sqlalchemy.orm import sessionmaker
Session = sessionmaker(engin)
session = Session()

增

def add_user():
    persopn = User(username='zhongxin',password='123456')
    session.add(persopn)#增加一个

    session.add_all(
        [
            User(username='zhongxin1', password='123456'),
            User(username='zhongxin2', password='123456'),
            User(username='zhongxin3', password='123456'),
            User(username='zhongxin4', password='123456'),
            User(username='zhongxin5', password='123456'),
        ]
    ) #增加多个
    session.commit()

删

def delete_user():
    rows = session.query(User).filter(User.username == 'zhongxin')[0]
    print(rows)
    session.delete(rows)
    session.commit()

改

def update_user():
    rows = session.query(User).filter(User.username=='zhongxin').update({User.password:111111})
    session.commit()

查

def search_user():
    rows = session.query(User).all()#查找全部
    print(rows)
    rows = session.query(User).first()#只查询第一个
    print(rows)

刚才写了一个repr,可以在查找的时候显示为正常的内容

def __repr__(self):
        return """
            <User(id:%s, username:%s, password:%s, creatime:%s, _locked:%s)>
        """ % (self.id, self.username, self.password, self.creatime, self._locked)
