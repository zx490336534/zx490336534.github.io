使用figma-developer-mcp

https://github.com/GLips/Figma-Context-MCP

获取token

1、登录https://www.figma.com/
2、左上角头像处点击Settings进入设置


3、在弹窗处点击「Security」点击「Generate new token」创建个人token

4、生效范围至少选择Read

连接

stdio方式启动

{
  "mcpServers": {
    "Figma AI Bridge": {
      "command": "npx",
      "args": [
        "-y",
        "figma-developer-mcp",
        "--stdio"
      ],
      "env": {
        "FIGMA_API_KEY": "figd_xxx"
      }
    }
  }
}

sse方式启动

npx figma-developer-mcp --figma-api-key=figd_xxx

http://localhost:3333/sse

使用

打开Figma，找到需要传递给AI的交互的链接

让它结合我的Figma交互稿编写一下测试分析文档

使用Figma自带方式

下载Figma客户端





使用 http://127.0.0.1:3845/mcp

使用


效果和figma-developer-mcp类似，不过官网的mcp提供了更多的工具
