主题：浏览器与应用开发

问题现象

在测试IOS中一个H5页面的时候发现保存时间接口传递的参数是null

但是在Web-Chrome和安卓上测试发现是正常的

原因分析

new Date("2022-01-17 10:00").getTime()

也就是在执行上面代码的时候，返回的内容是null

调试的时候看到提示：

Deprecation warning: value provided is not in a recognized RFC2822 or ISO format. moment construction falls back to js Date(), which is not reliable across all browsers and versions. Non RFC2822/ISO date formats are discouraged and will be removed in an upcoming major release. Please refer to http://momentjs.com/guides/#/warnings/js-date/ for more info.

找了下相关文档：

  • 本次测试中，iOS 环境可解析用 / 分隔的日期

  • 本次测试的 Android 环境可解析用 - 分隔的原日期

这里改用 / 是针对本次测试环境的兼容处理，不是 iOS 或 Android 的通用规则。非标准日期字符串在不同浏览器及版本中的解析结果可能不同

调试方案

每次修改代码后重新部署后，然后使用IOS设备进行测试非常的不方便

所以如果有Mac电脑的话，直接使用模拟器进行测试

查找可用的苹果模拟器并打开

找到可以用的模拟器，记住它的udid，例如136437DC-4D51-4628-B8CF-A4A3F3DFF1B0

xcrun simctl list

打开设备

open -a Simulator --args -CurrentDeviceUDID xxxx

完整的语句为：

open -a Simulator --args -CurrentDeviceUDID 136437DC-4D51-4628-B8CF-A4A3F3DFF1B0

打开电脑上的Safari浏览器

在开发-模拟器中打开Safari浏览器 页面检查器

在控制台输入刚才出问题的代码

> new Date("2022-01-17 10:00").getTime()
< NaN

同样的操作在Chrome上操作

判断环境并转化格式

判断当前环境

使用navigator.userAgent可以拿到当前请求的userAgent

let ua = navigator.userAgent
let isIOS = !!ua.match(/\(i[^;]+;( U;)? CPU.+Mac OS X/)

根据isIOS就可以判断，当前环境是否是IOS了，然后就可以给出我们需要的时间格式了

let formatter = isIOS ? 'YYYY/MM/DD HH:mm' : 'YYYY-MM-DD HH:mm'

在转化时间戳之前对格式进行处理

let t = "2022-01-17 10:00"
t = isIOS ? t.replace(/-/g,'/') : t
let new_t = new Date(t).getTime()

阅读视频文字稿

原文记录一次移动页面日期解析问题。

本片不测试任何平台，只给一张不明确的虚构纸历。

前两个位置分别写四和五，当缺少年月日位置说明时，有人读四月五日，有人读五月四日。

重点不是某个字符在哪台设备可用，而是输入能否不凭实现习惯、地区约定或猜测就表达同一个日历日期。

先说明要的是什么。

把展板布置的日期按年、月、日写成可核对的约定。

如果例子关注的是同一时刻而非日历的某一天，还要说时间和时区怎么确定。

这两种用法不能互换。

对读者展示的日期可以用熟悉的写法，但输入与互换使用什么结构要由系统明确。

这里不运行任何代码，只拿两种纸条对比。

请同伴分别检查三张纸。

一张用完整说明表达四月五日；一张只看到四和五，没有顺序；还有一张写二月三十日。

第一张人可以一致理解，第二张应标待确认，第三张在普通公历里并不存在。

读出来和真实语义正确不同。

也不应自动改变第三张，让生成的结果听起来顺滑，但已经不是给出的输入。

假想测试纸写一处有结果，一处为空。

可以说明这组课堂条件下结果不一致，但不能断言任何平台都永久如此。

修正思路是让数据约定更确定，并为无效或模糊输入保留不同反馈。

把展牌的显示方式与内部含义区分开，才能定位是哪份约定没有满足。

原文的记录属于历史个案，不是今天所有产品的能力比对。

最后两位同伴分别读一张不明确的日期，再读一张用同样方式明确标出年月日的虚构样本。

若第一张答案不同，应改约定或请人确认，不是猜哪边一定出错。

若第二张能独立复述一致的意思，才说明纸面规则更可读。

落实到报告里，就是记录原始条件、期望语义和观察差异，不把一个历史现象泛化成平台规律。
