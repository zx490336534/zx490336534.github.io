用 URL 文本片段把测试报告定位到具体一行

一份测试结果列出了未覆盖的函数。我想从列表点一下，直接打开覆盖率报告里对应的函数名。有些生成出来的 HTML 报告给章节加了锚点，却没有给每个函数一个单独的 id。这时可以用 URL 文本片段，让浏览器去页面里找已知文字。

先从一段能唯一匹配的文字开始

文本片段写在 URL 的片段部分。浏览器支持这项功能并且匹配成功时，会滚动到目标位置并高亮文本。下面的地址用于说明格式，report.html 和其中的文字都是构造示例。 MDN 文本片段说明

https://example.com/report.html#:~:text=calculateTotal

如果列表里拿得到模块名和函数名，可以先找报告上实际显示的名字。生成链接时，对文字部分做 URL 百分号编码，连接用的分隔符留在文字外面。空格可以编码为 %20，作为文本内容出现的短横线也需要编码为 %2D。

同一个函数名出现两次怎么办

报告可能在目录、结果表格和代码详情里都写了 calculateTotal。只传这个名字，浏览器会高亮第一个符合条件的匹配。可以用紧邻目标的前文或后文缩小范围。下面表示目标文字前面需要紧跟着 module B，两段中间允许有空白。

https://example.com/report.html#:~:text=module%20B-,calculateTotal

这里的前文有位置约束。如果 module B 只出现在另一个章节标题里，中间还隔着表头或其他文字，就不能用它来精确匹配这次示例。实际生成链接时，要从渲染后的报告里选相邻文字。

链接仍然要让人手动找得到

报告重新生成后，展示文字可能会变。匹配失败或浏览器不支持时，读者仍能打开这份报告，可以用链接旁的模块名和函数名继续查。有稳定章节锚点时，直接用章节锚点。页面只有可见文字时，再用文本片段补上定位。MDN 的示例页面能直接试一下滚动和高亮。 打开公开示例
