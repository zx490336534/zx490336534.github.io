配置playwright

{
  "command": "npx",
  "args": [
    "-y",
    "@playwright/mcp@latest",
    "--headless"
  ]
}

其他本地的mcp配置也类似
如果要配置sse类型的mcp则需要使用mcp-proxy，参考：

{
  "command": "mcp-proxy",
  "args": [
    "http://saas-help-mcp-dev.k8s-qunhe.qunhequnhe.com/cf-mcp"
  ]
}
