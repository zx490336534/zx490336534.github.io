AIHom 全栈课程体系

每节课都是一个独立 HTML。建议从上往下学；前端小白不要跳过“前端零基础”和“AIHom 前端入口”两段。已经熟悉的内容可以用搜索快速跳过。

阶段 1 · 后端与工程运行基础：先把服务跑起来、问题查清楚

  1. 001Spring AI 是什么 + AIHom 技术地图先知道 Java、Spring、Spring AI、AIHom 分别站在哪一层。
  2. 002Java 的类、对象、构造方法读懂后端代码里的 class、字段、构造方法、普通方法。
  3. 003Java 注解、接口、泛型、lambda拿下 Spring / Spring AI 代码里最常见的 Java 符号。
  4. 004Spring 依赖注入 DI + 三层注解理解对象为什么不用自己 new，以及 Controller / Service / Bean 怎么连起来。
  5. 005Spring Boot 自动配置 + starter + yml读懂 starter、自动配置和 application.yml 在项目启动时做什么。
  6. 006Maven 多模块 + Java 工程读法理解 common / client / web、父子 POM、依赖版本和 Java 8/21 边界。
  7. 007Spring Boot Web 三层最小闭环把 Controller、Service、Factory/Manager、Client/Mapper、DTO/VO 串起来。
  8. 008本地启动与配置体系理解 application.yml、profile、Nacos、Pilot/toad 和配置覆盖顺序。
  9. 009后端本地运行与部署基础理解 ai-native-service / auto-layout-service 怎么启动、构建、发布产物，以及 Pilot/toad 在部署中负责什么。
  10. 010前端本地运行与部署基础理解 ai-home、viewer-2d、render-3d 的 dev/build/pub:deploy 边界。
  11. 011Coops Agent 配置与 MCP 注入理解 Coops/Nacos/StateGraph 如何决定 Agent、Prompt、MCP Server、Skill 和工具注入。
  12. 012端到端环境排查清单用固定顺序排查前端、后端、配置、WebSocket、Agent、Tool、基础设施依赖和 viewer 展示问题。
  13. 013Git、Kaptain 与发布分支基础理解从 Kaptain 事项拉功能分支、提 MR、合入 release/日期分支、上线和回滚的路径。
  14. 014日志、Trace、断点与 WebSocket 排查从浏览器 Network/WebSocket 到 QHLogger、traceId、handler、Agent 和 Tool。

阶段 2 · Spring AI 与 Agent：理解 AIHom 智能能力

  1. 015Spring AI vs Spring AI Alibaba + DashScope理解 AIHom 为什么是 Spring AI + Alibaba + DashScope 这一套。
  2. 016ChatClient + Prompt + 消息体系第一次写出能跑的聊天逻辑，理解 prompt/user/system/call/content。
  3. 017流式响应 + 结构化输出 + 会话记忆理解聊天页面为什么能流式输出、返回结构化结果和支持多轮。
  4. 018Tool Calling + MCP理解大模型如何动手，以及为什么 AIHom 会把部分 Tool 委托给前端。
  5. 019RAG 检索增强生成理解先查资料再回答的两段式流程。
  6. 020Agent + StateGraph / Graph理解 AIHom 的 Agent 编排：节点、边、状态、路由和 Supervisor。

阶段 3 · 前端零基础：先补浏览器和页面地基

  1. 021前端零基础 01：网页由什么组成分清 HTML、CSS、JavaScript、React、TypeScript、Rspack 的角色。
  2. 022前端零基础 02：HTML 与 DOM知道页面元素从哪里来，能看懂浏览器 Elements 面板。
  3. 023前端零基础 03：CSS 先看布局先学会看尺寸、间距、flex、position、z-index、overflow。
  4. 024前端零基础 04：JavaScript 变量、函数、事件看懂存一个值、定义一个动作、点击时执行。
  5. 025前端零基础 05：浏览器调试先看三块固定 Console、Network、Elements 的排查顺序。
  6. 026前端基础 06：JavaScript 异步运行模型理解 Promise、async/await、事件循环和回调为什么会晚点执行。
  7. 027前端基础 07：TypeScript 类型系统读懂 interface、type、union、generic，以及类型和运行时数据的边界。
  8. 028前端基础 08：浏览器、网络与 DOM知道 DOM、Network、WebSocket、iframe/postMessage 各自负责什么。
  9. 029前端基础 09：CSS 布局与样式排查用盒模型、flex、position、overflow、z-index 排查常见布局问题。
  10. 030前端基础 10：React 渲染模型理解 props、state、render、effect/lifecycle，以及 UI 为什么会随数据变化。
  11. 031前端基础 11：工程化、调试与测试理解 package.json、Rspack、source map、DevTools 和前端测试分层。

阶段 4 · AIHom 前端入口：从一个动作进入项目机制

  1. 032AIHom 前端入口 01：读 TSX 组件先会看 props、JSX、render、onClick，读懂一个组件在画什么。
  2. 033AIHom 前端入口 02：状态管理基础从页面现象倒推：数据在哪里、谁改了它、哪个组件读了它。
  3. 034AIHom 前端入口 03：一次页面动作的数据流用“点击发送”串起组件、Manager、Service、WebSocket 和后端。
  4. 035AIHom 前端入口 04：接口请求与数据契约理解前端 TypeScript 类型和后端 DTO/VO 如何对齐。
  5. 036AIHom 前端入口 05：WebSocket 消息入门先会在浏览器里看 type、key、data，判断消息属于哪条链路。
  6. 037AIHom 前端入口 06：iframe/postMessage 与 viewer 边界先把 ai-home、viewer-2d、render-3d 的页面边界和消息边界分清楚。
  7. 038AIHom 前端入口 07：SDK + MCP 工具桥看懂 tool_call 到前端执行，再回 tool_response 的主线。
  8. 039AIHom 前端入口 08：异步任务与状态机基础用“提交任务、查状态、拿结果”理解布局、截图和渲染任务。
  9. 040AIHom 前端入口 09：跨仓开发工作流接需求时先判断影响仓库、接口边界和联调顺序。

阶段 5 · 核心工程深入：进入真实代码专项机制

  1. 041ai-native-service 项目全景理解后端核心仓库结构、架构和关键入口。
  2. 042auto-layout-service 项目全景理解 AI 自动布局引擎、Processor 模式和核心数据流。
  3. 043ai-home 前端项目全景理解主前端从 App.tsx 到画布、对话和 Viewer 的完整链路。
  4. 044viewer-2d 项目全景理解 2D 户型渲染器的架构、核心系统和数据流。
  5. 045render-3d 项目全景理解 3D 渲染容器、离线出图流程和父页面同步机制。
  6. 046ai-native-service 深度追踪从 WebSocket 到 Tool 调用，逐层追踪一条消息的完整代码路径。
  7. 047auto-layout-service 深度追踪深入自动布局引擎的 Processor 模式、数据流与双通道并行架构。
  8. 048ai-home 前端深度追踪追踪 URL 路由、状态管理、MCP 工具桥接和 AI 对话通信。
  9. 049viewer-2d 深度追踪从 DfScene2d 初始化到外部同步机制的完整追踪。
  10. 050render-3d 深度追踪拆解 3D 渲染容器的状态机、模板缓存、父页面同步和渲染轮询。
  11. 051StateGraph 内部机制深入 StateGraph 的数据结构、编译过程、执行引擎、检查点和条件路由。
  12. 052双通道并行布局算法理解 auto-layout-service 如何通过 RAG + PRODUCT_CONFIG 并行执行布局任务。
  13. 053AI 服务集成与模型调用理解 auto-layout-service 中大模型服务的接入方式和调用边界。
  14. 054reactive-framework 深入深入 observable、observer、computed、combine 与 connect 的协作。
  15. 0552D/3D Viewer 集成与通信理解 ai-home 如何嵌入 viewer-2d/render-3d，以及 postMessage/MCP 协作。
  16. 056PixiJS 渲染引擎与 Scene2D掌握 viewer-2d 的 PixiJS 核心概念、Scene2D 渲染管线和视图注册。
  17. 057实体系统与 Drawable 绑定理解 Entity、Drawable、Selectable 三大抽象和实体生命周期。
  18. 058离线渲染管线详解从渲染任务提交到结果回写，理解 OfflineRenderStateManager 的出图链路。
  19. 059模板系统与灯光/背景管理理解模板配置、obsConfigCache、灯光样式映射、背景配置和默认回退。
  20. 060跨仓库集成指南理解核心工程如何协作，以及数据如何在它们之间流动。
