AI 应用全栈实战

从一次布局生成，学会前后端联调与 Agent 故障恢复。

用虚构的 RoomLab 串起界面、任务服务、Agent 和二维／三维视图。适合想从测试进入 AI 应用开发的人。

从第 1 课开始直接看实战

怎么学

每一节，分两遍读

  1. 第一遍跑通：从一个场景出发，画出正常调用链。
  2. 第二遍读代码：顺着输入、分支和状态查到结果，用失败用例验证。
  3. 最后做实战：跑示例项目，对照测试断言。

跑通前后端拆分服务与模型还原流式与工具调用稳住状态与持久化测试、观测与评测端到端实战

阶段 01

跑通前后端

从一次提交开始，逐步读懂 HTTP、请求取消与运行时数据。产出：一份带正常与失败分支的接口契约。

  1. 001一次交互如何走完整条链路从用户点击「生成布局」开始，找到浏览器、服务端和渲染器各自负责什么。21 分钟↗
  2. 002读懂一次生成请求的 HTTP 与 JSON从请求方法、响应码、响应体三个位置判断下一步。30 分钟↗
  3. 003取消请求与防止旧结果覆盖同时处理真正的取消和没有被及时取消的迟到响应。33 分钟↗
  4. 004类型声明不够：校验网络里的 unknown在边界验证布局数据，再把它交给业务代码。32 分钟↗
  5. 005页面状态：别让加载、空结果与失败互相冒充区分首次加载、刷新旧结果、成功但为空，以及失败后的重试入口。26 分钟↗

阶段 02

拆分服务与模型

把业务判断和外部模型分开，收紧结构化输出与上下文边界。产出：一条不依赖真实模型的可测链路。

  1. 006拆开接口、业务规则和外部模型先跑通一个可测的后端切片，再接入真实模型。25 分钟↗
  2. 007让模型输出可验证的布局草案分开文本解析、结构校验、领域校验与修复。36 分钟↗
  3. 008给每个任务一份独立而可重现的上下文防止并行任务把不同房间的规则拼到同一次模型调用。36 分钟↗
  4. 009检索增强：让布局建议有证据可核对让模型引用真正用到的约束，并对过期或不相干的规则选择不下结论。26 分钟↗

阶段 03

还原流式与工具调用

从完整事件帧读到断线恢复，再看 Agent 如何推进和调用工具。产出：能回放乱序、重复和缺失事件的用例。

  1. 010区分流字节、消息帧与业务事件看清为什么数据一次读到了也不等于事件完整。38 分钟↗
  2. 011流式事件：断线、乱序与旧响应给每个事件一个版本，用断线与乱序测试验证恢复。29 分钟↗
  3. 012Agent 状态图：可恢复不等于可重试把生成、校验、提交做成明确节点，避免恢复时重复写入。31 分钟↗
  4. 013工具与 MCP：从发现到审批区分工具可见、可调用和被允许写入三件事。27 分钟↗

阶段 04

稳住状态与持久化

把版本冲突、任务认领、通知发送和视图更新串起来。产出：一个能复现崩溃后恢复的实验。

  1. 014一条条件更新保护两个并发编辑看懂版本比较为何要和更新一起发生。37 分钟↗
  2. 015工作进程重启后如何接回任务用领取、租约和完成条件模拟安全接手。39 分钟↗
  3. 016写入已成功，完成事件为何可能没发出用同一事务存版本与待送事件，并练习重发与去重。39 分钟↗
  4. 017二维和三维怎么共用一份状态理解坐标、选择状态与版本在不同视图之间如何同步。28 分钟↗

阶段 05

测试、观测与评测

把代码走查变成可重复的测试，区分结果质量、延迟和系统故障。产出：一张定位问题的证据表。

  1. 018一条布局需求如何拆成三层测试区分组件输入、接口契约与集成链路，让失败定位到具体边界。36 分钟↗
  2. 019按一次运行排查前端到模型的故障把一条反馈定位为连接、编排、生成或渲染问题。28 分钟↗
  3. 020把一次失败变成可汇总的运行指标用低基数维度统计失败，明白日志与指标各该记录什么。35 分钟↗
  4. 021区分等待、模型慢和渲染慢根据耗时边界定位瓶颈，避免把并行时间重复算进总耗时。35 分钟↗
  5. 022用固定样本验证模型改变后有没有退化把几何硬约束和偏好评分分开，保留失败个案。39 分钟↗

阶段 06

端到端实战

用前面的机制完成一次功能演进，并准备基准、异常复现与回滚证据。

  1. 023综合实战：布局生成到故障恢复用一个完整流程串起前面七节，并得到可复述的验收结果。45 分钟↗
  2. 024真实项目练习：批量生成与安全回退按房间隔离进展和失败，从小范围发布到可回退。41 分钟↗
