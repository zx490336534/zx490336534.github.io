让模型输出可验证的布局草案

分开文本解析、结构校验、领域校验与修复。

先看场景

模型给出像 JSON 的结果，但有多余字段、断掉的输出或越界家具。应用要说明是哪一层失败。

结构化输出：让结果满足预先规定的字段、类型和分支。

走一遍

  1. 保留可解析的结构。
  2. 仅接纳定义好的字段。
  3. 领域规则最后判断能否落图。
合成示例 可折叠

第二遍 · 把代码读懂

代码拆解

怎样把内容不对与格式不对分别复现？

调用链

  1. 抓取完成的候选。
  2. 解析成对象。
  3. 验证字段与业务边界。
  4. 按类别决定修复或放弃。
Python 示例 可折叠

可复制到 lesson.py，再运行 python3 lesson.py。

import json

def extract(text, room_width):
    try:
        value = json.loads(text)
    except json.JSONDecodeError:
        return "parse-error", None
    if not isinstance(value, dict) or set(value) != {"left", "width"}:
        return "invalid-shape", None
    left, width = value["left"], value["width"]
    if type(left) is not int or type(width) is not int:
        return "invalid-shape", None
    if left < 0 or width <= 0 or left + width > room_width:
        return "out-of-bounds", None
    return "candidate", (left, width)

assert extract('{"left":', 4) == ("parse-error", None)
assert extract('{"left":true,"width":1}', 4) == ("invalid-shape", None)
assert extract('{"left":3,"width":2}', 4) == ("out-of-bounds", None)
assert extract('{"left":3,"width":1}', 4) == ("candidate", (3, 1))

提示词是合作，不是校验

即便模型受结构约束，调用也可能被截断或返回拒绝。适配器只在得到完整候选后向下交付。

字段齐全不能证明布局正确

left 和 width 均为整数却依旧可能超出房间。示例将 parse、invalid-shape 和 out-of-bounds 分开。

修复有限次并保留边界

只把字段级失败反馈给模型。修复不能放宽边界；再次返回坏结果时终止，不能替换已经展示的布局。

复现失败

生成被截断
怎么触发：候选只写完一半。
怎么判断：返回解析错误，不进入写工具。
合法结构但坐标超线
怎么触发：left=3、width=2 而房间宽 4。
怎么判断：判定领域错误，不把失败归给解析器。

写下这些测试断言

  • 解析与规则有不同错误码。
  • 布尔值不会误当整数坐标。
  • 几何约束通过也只代表得到候选，并未保存。

这一课带走：模型产出只是候选，能否发布由应用的验证与决策共同决定。
