062 ai-native-service 开发实战

常见开发任务的 step-by-step 指南

1. 如何新增一个本地 Tool

当 AI Agent 需要调用新的后端能力时，你需要创建一个 Tool。

1 创建 Tool 类

在 tool/ 目录下新建 Java 类，继承 AbstractToolCallBack：

@Component
public class MyNewTool extends AbstractToolCallBack {

    @Override
    public String getName() {
        return "my_new_tool";  // 工具唯一标识
    }

    @Override
    public String getDescription() {
        return "描述这个工具做什么，LLM 会根据描述决定何时调用";
    }

    @Override
    public String getParameters() {
        // 返回 JSON Schema 格式的参数定义
        return """
            {
                "type": "object",
                "properties": {
                    "input": {"type": "string", "description": "输入参数"}
                },
                "required": ["input"]
            }
            """;
    }

    @Override
    public String execute(Map<String, Object> args) {
        // 实际执行逻辑
        String input = (String) args.get("input");
        // ... 业务逻辑 ...
        return JSONUtils.toJSONNoException(result);
    }
}
2 注册到 ToolCallBackFactory

在 factory/ToolCallBackFactory.java 中添加新 Tool 的注册。确保它被包含在对应 Agent 的工具列表中。

3 在 Nacos 配置中绑定

在 Nacos 配置中心的对应 Agent 配置中，将新工具名添加到 tools 列表。

4 测试

本地启动服务，通过前端对话触发对应场景，检查 Langfuse trace 中工具是否被正确调用。

2. 如何新增一个子 Agent

1 在 Nacos 中配置 Agent

添加新的 Agent 配置：名称、prompt、模型、工具列表、温度等参数。

2 在 Supervisor 中注册路由

修改 Supervisor 的 prompt 或路由配置，让它知道新 Agent 的存在和适用场景。

3 在 StateGraph 中添加节点

如果需要自定义节点逻辑，在 node/ 目录下创建适配器，或使用默认的 AgentNodeAdapterImpl。

3. 如何新增 Controller 接口

@RestController
@AccessControlAllowEnable
public class MyController extends BaseController {

    @Resource
    private MyService myService;

    @PostMapping(UriConstants.MY_ENDPOINT)
    @LoginCheck  // 需要登录
    public Result<MyResponseVo> myMethod(@RequestBody MyRequestVo reqVo) {
        // 参数校验
        BeanValidator.validate(reqVo);
        // 业务逻辑
        MyResponseVo result = myService.doSomething(reqVo);
        return Result.ok(result);
    }
}
规范
  • URI 常量定义在 constants/UriConstants.java
  • 依赖注入用 @Resource 不用 @Autowired
  • 请求/响应 VO 放在 vo/ 目录
  • 错误码定义在 enums/ErrorCodeEnum.java

4. 如何修改 Supervisor 路由

Supervisor 的路由逻辑由 Nacos 配置驱动，不需要改代码：

  1. 登录 Nacos 配置中心
  2. 找到 Supervisor Agent 的配置
  3. 修改 prompt 中的路由规则描述
  4. 修改子 Agent 列表和工具绑定
  5. 配置热更新，无需重启

6. 本地运行和调试

# 1. 确保 JDK 21
java -version

# 2. 编译（跳过测试）
mvn clean install -DskipTests

# 3. 启动（dev 环境）
java -jar ai-native-service-web/target/ai-native-service-0.0.1-SNAPSHOT.war \
  --add-opens java.base/java.lang=ALL-UNNAMED \
  -Dspring.profiles.active=dev \
  -Dstage=dev

# 4. 检查日志
tail -f logs/ai-native-service.log
