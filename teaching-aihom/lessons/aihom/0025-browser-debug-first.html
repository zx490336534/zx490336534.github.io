025 前端零基础 05：浏览器调试先看三块

目标：前端出问题时，不乱猜。先看 Console、Network、Elements 三块。

1. 三个面板各看什么

面板用途常见问题
Console看 JS 报错和日志点击后红色报错
Network看 HTTP / WebSocket 请求请求失败、消息没回来
Elements看 DOM 和 CSS按钮不见、弹窗被挡

2. 固定排查顺序

  1. 先看 Console 有没有红色错误。
  2. 再看 Network 请求有没有发出去。
  3. 最后看 Elements 里元素是否存在、样式是否异常。

3. AIHom 里多看 WebSocket

AI 对话不是普通一次 HTTP 请求结束。它会通过 WebSocket 持续收消息。Network 里点开 WebSocket，再看 Frames，可以看到前后端来回发的消息。

后面学习 SDK、MCP、viewer 截图时，都要回到这个排查顺序：Console 看报错，Network 看消息，Elements 看页面结果。

4. 前端问题先分类

现象优先看常见判断
点击后没反应Console是否有 JavaScript 报错
接口没有返回NetworkHTTP 状态码、请求参数、响应体
AI 回复断了Network / WS FramesWebSocket 是否收到消息帧
数据到了但页面不变Elements + React 状态DOM 是否存在，状态是否触发渲染

5. 本课练习：保留一个最小问题包

遇到前端问题时，先收集四样东西再问 agent 或同事：

  1. Console 第一条红色错误。
  2. Network 里失败请求的 URL、状态码、响应体。
  3. 如果是对话问题，WebSocket Frames 里最后一条消息。
  4. 页面上预期看到什么、实际看到什么。
Q: 消息发出后没有回复，优先看哪里？
  • A. Git branch
  • B. Network / WebSocket
  • C. 字体大小
