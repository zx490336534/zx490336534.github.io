022 前端零基础 02：HTML 与 DOM

目标：知道页面元素从哪里来。以后打开浏览器 Elements 面板，能看懂最基本的结构。

1. HTML 是页面结构

<div class="chat">
  <input placeholder="输入需求" />
  <button>发送</button>
</div>

这段只说明页面上有什么：一个输入框、一个按钮。它还没有说明按钮点了会发生什么。

2. DOM 是浏览器看到的页面树

浏览器读完 HTML 后，会生成一棵 DOM 树。DevTools 的 Elements 面板看到的就是 DOM。

div.chat
  input
  button

3. React 和 DOM 的关系

React 不是 DOM。React 组件返回 JSX，React 再把 JSX 变成 DOM。你看源码时看 JSX；你调试页面时看 DOM。

4. AIHom 里怎么用

对话输入框、发送按钮、消息列表、画布容器，最终都会变成 DOM。viewer-2d / render-3d 通常嵌在 iframe 里，所以它们有自己的 DOM 树。

5. 从源码到页面的最小链路

TSX / JSX 源码
  -> React 渲染
  -> 浏览器 DOM
  -> Elements 面板里能看到的节点

所以读前端时要分两步：源码里看 return (...) 或 render() 画了什么；浏览器里看 Elements 面板确认它最后有没有真的出现在页面上。

排查页面“看不见”时，先不要猜 CSS。第一步先确认 DOM 里有没有这个节点。DOM 里没有，说明 React 没渲染出来；DOM 里有但页面看不见，再去查 CSS。

6. 本课练习：判断问题在 React 还是 CSS

  1. 打开页面，选中一个按钮。
  2. 如果 Elements 找不到它，优先查 React 条件渲染和数据状态。
  3. 如果 Elements 找得到它，但页面不显示，优先查 CSS 的尺寸、颜色、定位、层级。
