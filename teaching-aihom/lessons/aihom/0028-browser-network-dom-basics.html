028 前端基础 08：浏览器、网络与 DOM

目标：知道浏览器里页面、DOM、Network、WebSocket、iframe/postMessage 各自是什么，能用 DevTools 定位前端问题。

1. 浏览器给前端代码的四类能力

能力你会在哪里看到AIHom 场景
DOM页面元素树按钮、输入框、对话消息列表
NetworkHTTP / WebSocket 请求打开会话、发消息、取配置
Storage本地缓存用户偏好、临时状态、调试开关
iframe嵌入另一个页面ai-home 嵌 viewer-2d / render-3d

2. DOM 不是 React，但 React 会更新 DOM

React 组件返回 JSX，React 再把它变成真实 DOM。你在 Elements 面板看到的是结果，不是源码本身。

React state 变化
  -> 组件重新 render
  -> React 比较前后差异
  -> 更新真实 DOM

3. Network 面板：全栈排查第一站

前端出问题时，先看 Network：请求有没有发出去、状态码是多少、响应体是什么、WebSocket frame 里 key 和 data 是否符合预期。

问题优先看
按钮点了没反应Console 是否报错，Network 是否有请求
消息发了没回复WebSocket frames 里是否有 SendMessage 和响应
viewer 不同步iframe 的 postMessage 类型和方向

4. postMessage：iframe 边界的“传话筒”

ai-home 和 viewer 不是同一个 JS 运行上下文。它们通过 window.postMessage 传消息。

ai-home
  window.postMessage({ type: 'REFRESH_VIEWER', data })
      ↓
viewer iframe
  window.addEventListener('message', handler)
Q1: viewer iframe 内部代码能直接读 ai-home 的 React state 吗？
  • A. 能，所有页面共享 state
  • B. 不能，要通过消息通信
  • C. 能，只要 CSS 同名
