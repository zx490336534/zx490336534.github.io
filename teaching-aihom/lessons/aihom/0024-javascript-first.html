024 前端零基础 04：JavaScript 变量、函数、事件

目标：能看懂最基本的前端逻辑：存一个值、定义一个动作、点击时执行。

1. 变量：给数据起名字

const text = '帮我设计一个客厅';
let loading = false;

const 表示这个名字不会重新指向别的值；let 表示后面可能会改。

2. 函数：给动作起名字

function sendMessage(text) {
  console.log('发送消息', text);
}

读函数时只问三件事：输入是什么、里面做什么、输出是什么。

3. 事件：用户做了什么

button.onclick = function () {
  sendMessage(text);
};

事件就是“先登记一段函数，等用户点击、输入、滚动、收到消息时再执行”。

4. AIHom 里对应什么

  • 点击发送：执行发送消息函数。
  • WebSocket 收到回复：执行消息处理函数。
  • iframe 回传截图完成：执行回调函数。

5. 读函数时固定问三句话

问题看哪里例子
输入是什么函数括号里的参数sendMessage(text) 的 text
中间做什么函数体里的语句校验、调用接口、更新状态
结果给谁return 或回调返回 Promise，或触发 UI 更新
小白不用一开始背所有语法。先能认出 const、let、function、() =>、return，就能读懂很多前端逻辑的骨架。

6. 本课练习：追一次点击

  1. 在源码里找按钮上的 onClick 或 onclick。
  2. 找到它调用的函数。
  3. 按“输入是什么、中间做什么、结果给谁”三句话复述一遍。
Q: function sendMessage(text) 里的 text 是什么？
  • A. CSS 颜色
  • B. 函数输入参数
  • C. 后端类名
