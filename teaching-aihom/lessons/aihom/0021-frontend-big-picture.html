021 前端零基础 01：网页由什么组成

目标：先建立前端最小地图。后面看到 React、TypeScript、viewer、SDK，不会觉得它们是同一团东西。

一句话：前端就是“浏览器里运行的界面程序”。它负责展示页面、响应点击、调用后端、把结果画出来。

1. 三个最基础角色

角色负责什么类比
HTML页面有哪些东西房子的结构
CSS这些东西长什么样装修和布局
JavaScript点击后发生什么电路和开关

2. React、TypeScript、Rspack 又是什么

名字先这样理解
React帮你把页面拆成组件，并在数据变化时更新界面
TypeScript给 JavaScript 加类型提示，减少写错字段和参数
Rspack把源码打包成浏览器能加载的文件

3. AIHom 前端多了什么

AIHom 不只是普通表单页面。它有右侧 AI 对话、左侧画布、2D/3D viewer、WebSocket 消息、前端工具调用。你不需要一开始全懂，先知道它们都运行在浏览器里。

4. 读前端代码先抓四条线

线索你要问的问题AIHom 例子
页面结构界面上有哪些区域对话区、画布区、viewer iframe
数据状态当前记住了什么会话列表、当前户型、是否加载中
用户事件用户做了什么点击发送、拖动画布、切换方案
网络消息前后端交换了什么HTTP 请求、WebSocket 消息、MCP 工具结果
小白最容易犯的错，是把 React、TypeScript、Rspack 当成同一件事。先记住分工：React 管“怎么组织界面”，TypeScript 管“字段和参数别写错”，Rspack 管“源码怎么变成浏览器能跑”。

5. 本课练习：打开任意网页做一次识别

  1. 打开浏览器 DevTools。
  2. 在 Elements 里点一个按钮，确认它是 DOM 元素。
  3. 想一句话：这个按钮的样式由 CSS 决定，点击动作由 JavaScript 决定。
  4. 回到 AIHom 时，用同样方式看“发送”按钮和 viewer 容器。
