029 前端基础 09：CSS 布局与样式排查

目标：看到 ai-home 的画布、侧栏、对话框、viewer 容器时，能判断布局问题大概率出在 flex、position、overflow 还是 z-index。

1. 盒模型：每个元素都是一个盒子

content 内容
padding 内边距
border 边框
margin 外边距

排查尺寸不对时，先在 DevTools 的 Computed 面板看盒模型，而不是直接猜 CSS。

2. flex：最常见的一维布局

AIHom 里左画布、右对话、工具栏、按钮组，经常是 flex。

.page {
  display: flex;
}
.canvas {
  flex: 1;
}
.chat {
  width: 360px;
}
属性读法
display: flex子元素排成一行或一列
flex: 1吃掉剩余空间
gap子元素之间的间距

3. position、overflow、z-index

现象优先查
弹窗被盖住z-index 和父级 stacking context
内容被裁掉overflow: hidden
浮层位置不对position: absolute/fixed 的参考对象
移动端挤爆固定宽度、最小宽度、flex 收缩
AIHom 读法

前端功能问题先看数据流；纯视觉问题先看盒模型和布局。不要一上来改一堆样式，先在 DevTools 临时开关 CSS，确认是哪一条规则影响了结果。

Q1: 对话面板宽度固定、画布占剩余空间，最常见会用什么？
  • A. flex 布局
  • B. SQL 查询
  • C. Java 注解
主资料

优先看 MDN 的 Box model 和 Flexbox。
