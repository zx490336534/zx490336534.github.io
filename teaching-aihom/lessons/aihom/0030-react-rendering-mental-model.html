030 前端基础 10：React 渲染模型

目标：知道 props、state、render、effect、class lifecycle 的关系，能解释“为什么状态变了 UI 会变”。

1. React 组件就是“数据 → UI”的函数

无论是 class component 还是 function component，都可以先按这个模型读：

props + state
  -> render()
  -> JSX
  -> React 更新页面

2. props 和 state 的区别

概念谁拥有AIHom 读法
props父组件或 connect 注入这个组件从外面收到什么
state组件自己或 manager这个组件/业务当前记住了什么
renderReact 调用根据数据画出什么 UI

3. class component 和 hooks 对照

// class 写法
componentDidMount() { start(); }
componentWillUnmount() { stop(); }

// hooks 写法
useEffect(() => {
  start();
  return () => stop();
}, []);

读法：组件出现时做初始化，组件销毁时清理订阅、计时器、消息监听。

4. AIHom 里别把所有状态都塞 useState

项目特征

ai-home 有自己的状态管理：ConversationManager、ViewerStateManager、RootStateManager、@qunhe/reactive-framework。小组件临时状态用 useState；跨组件业务状态优先找 manager。

5. 排查 UI 不更新的三问

  1. 状态真的变了吗？看 manager 字段或 React DevTools。
  2. 组件真的读了这个状态吗？看 props / connect / observer。
  3. 读状态的组件是否被响应式系统包住？看 @observer 或 connect。
Q1: 一个组件 UI 是否变化，最核心取决于什么？
  • A. 文件名是否很短
  • B. CSS 是否都写成红色
  • C. 它读取的数据是否变化
