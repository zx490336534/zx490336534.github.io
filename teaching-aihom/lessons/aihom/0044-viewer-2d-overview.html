044 viewer-2d 项目全景

理解 2D 户型渲染器的架构、核心系统和数据流

1. 这个项目是什么

viewer-2d 是 AI Home 的 2D 户型渲染器。它在浏览器中绘制户型图 — 墙体、门窗、房间、家具、标注 — 并处理用户的选中、拖拽、缩放、旋转等交互。

一句话定位

基于 PixiJS + KAF 的 2D 场景插件，嵌入 ai-home 主应用的 iframe 中，负责"画户型图 + 处理交互"。

2. 技术栈

技术版本用途
React16.xUI 视图层
TypeScript~3.8.3类型安全（较老版本，注意兼容性）
PixiJS@qunhe/pixi.js2D WebGL 渲染引擎
KAF@qunhe/kaf插件化框架 + StateManager + Scene2D
Rspack@rspack/core构建工具
SCSS-样式（CSS Modules + styled-components 混用）
注意

TypeScript 版本是 3.8，很老。不能用现代 TS 特性。禁止在仓库内直接运行 tsc（会污染 src/），用 kjl ci:lint 做检查。

3. 核心架构

viewer-2d 不是一个纯 React 页面，而是 React 视图 + KAF StateManager + Scene2D 场景 的组合：

┌─────────────────────────────────────────────┐
│  ai-home (父页面)                           │
│  通过 iframe 嵌入 viewer-2d                  │
│  postMessage 双向通信                        │
└──────────────────┬──────────────────────────┘
                   │ postMessage
┌──────────────────▼──────────────────────────┐
│  viewer-2d                                   │
│                                              │
│  ┌─────────────┐  ┌──────────────────────┐  │
│  │ React 视图   │  │ Scene2D (PixiJS)     │  │
│  │ - 左面板     │  │ - 墙体/门窗/房间     │  │
│  │ - 尺寸标注   │  │ - 家具/标注          │  │
│  │ - 加载态     │  │ - 拖拽/缩放/旋转     │  │
│  └──────┬──────┘  └──────────┬───────────┘  │
│         │                    │               │
│  ┌──────▼────────────────────▼───────────┐  │
│  │       RootStateManager (KAF)          │  │
│  │  scene2D + selectedControl + layout   │  │
│  │  + outside + leftPanel                │  │
│  └───────────────────────────────────────┘  │
└─────────────────────────────────────────────┘

5. 核心概念

RootStateManager

整个应用的"状态中枢"，组合了 scene2D、selectedControl、layout、outside、leftPanel 等子状态。React 通过 connect() 连接它。

Scene2D

PixiJS 驱动的 2D 场景。在 DfScene2d.tsx 的 onInit 中注册视图、系统和推理能力。所有 2D 渲染都在这里。

Entities（实体）

领域对象的 2D 可视化 — 门、窗、房间、标注等，每个实体有自己的 Drawable 绑定。

OutsideStateManager

负责与父页面（ai-home）的 postMessage 通信。同步房间信息、预览图、显示规则等。
