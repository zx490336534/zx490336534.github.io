023 前端零基础 03：CSS 先看布局

目标：不系统学 CSS，先学会看懂“为什么这个东西在这里、为什么挤到一起、为什么被挡住”。

1. CSS 管样式和位置

属性先这样理解
width / height元素尺寸
margin / padding外面的空白 / 里面的空白
display: flex让子元素横向或纵向排列
position决定元素按普通流、固定位置、绝对位置摆放
z-index谁盖在谁上面

2. AIHom 常见布局问题

  • 右侧对话框宽度不对：看容器宽度和 flex。
  • 弹窗被盖住：看 position 和 z-index。
  • 内容被截断：看 overflow。
  • 按钮文字挤在一起：看 padding、width、white-space。
小白排查顺序：先在 Elements 选中元素，再看右侧 Styles 和 Computed。不要一上来全局搜 CSS。

3. 先学盒模型，再学布局

概念先这样理解排查什么
content文字、图片、按钮本体内容是否太长
padding内容和边框之间的空白按钮是否太挤
border元素边界实际范围在哪里
margin元素和外界的距离两个区域是否贴太近

4. 本课练习：用 Computed 面板查一次尺寸

  1. 在 Elements 里选中一个元素。
  2. 切到 Computed，看盒模型图里的 margin、border、padding、content。
  3. 如果文字被挤压，先看 content 宽度和 padding；如果区域相互覆盖，再看 position 和 z-index。
