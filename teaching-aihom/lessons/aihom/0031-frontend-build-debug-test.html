031 前端基础 11：工程化、调试与测试

目标：知道 package.json、构建器、source map、DevTools、前端测试在开发链路里各自负责什么。

1. package.json 是前端工程入口

读一个前端仓库，先看 package.json：脚本、依赖、React/TypeScript 版本、构建工具都在这里。

字段读法
scripts怎么启动、构建、测试
dependencies线上运行需要什么
devDependencies开发和构建需要什么
resolutions强制依赖版本，排查依赖冲突时要看

2. 构建器：把 TSX/CSS/资源变成浏览器能跑的文件

ai-home 使用 Rspack 相关构建链路。构建器负责处理 TypeScript、JSX、CSS、图片、代码拆分和开发服务器。

源码 TSX / CSS / 图片
  -> Rspack 编译
  -> 浏览器加载 JS / CSS
  -> DevTools 通过 source map 映射回源码

3. 前端调试四件套

工具用来查什么
Console运行时错误、日志、对象结构
NetworkHTTP、WebSocket、响应体、耗时
ElementsDOM、CSS、布局、z-index
Sources断点、调用栈、source map

4. 测试：前端也要分层

层级适合测什么
单元测试纯函数、状态转换、工具方法
组件测试输入、按钮、局部 UI 状态
E2E真实浏览器里的完整流程，viewer-2d 已有 Playwright 方向
全栈排查顺序

先复现，再看 Console/Network；有请求就拿 traceId 去后端查；没有请求就回到 React 事件、状态和按钮可用条件。这样不会在前后端之间来回乱跳。

Q1: 前端请求发出去了但后端报错，最该拿什么去串日志？
  • A. CSS 类名
  • B. traceId / request id
  • C. 按钮圆角
主资料
