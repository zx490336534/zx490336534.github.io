032 AIHom 前端入口 01：读 TSX 组件

目标：打开一个 TSX 文件时，不再被语法吓住；能先分清“输入是什么、页面画什么、点击后做什么”。

先别急着懂全部

TSX 文件就是“TypeScript 代码 + React 页面结构”。第一次读只抓三件事：props 是外部传进来的数据，state 是组件自己记住的数据，return 里的 JSX 是最终画出来的页面。

1. 读 TSX 的固定顺序

第一步：看文件名和导出。例如 AIChatDrawer.tsx 大概率就是聊天抽屉。
第二步：看 Props。interface XxxProps 告诉你这个组件需要别人传什么。
第三步：看 render 或 return。这里决定页面上画什么。
第四步：看 onClick / onChange。这些地方通常是用户操作入口。

2. Props：别人递给组件的东西

看到这种代码，不要先纠结类型细节。先翻译成人话：这个组件需要 open、documentReady、rootState 这些输入。

interface AIChatDrawerProps {
  aiChatDrawerOpen: boolean;
  documentReady: boolean;
  rootState: RootStateManager;
}

读法：boolean 表示真假，RootStateManager 表示一个对象。对象里面还有更多状态，下一课会讲。

3. JSX：页面长什么样

JSX 很像 HTML，但可以嵌入变量。看到 {...} 就读成“这里放一个 JS 表达式的结果”。

return (
  <div className={styles.drawer}>
    {isLoading && <span>thinking...</span>}
    <InputArea isLoading={isLoading} />
  </div>
);

这段不用背语法。你只要知道：isLoading 为真时显示 loading，并把 isLoading 继续传给 InputArea。

4. class component 和 function component

形态怎么看AIHom 例子
class Xxx extends React.Component重点看 render()、componentDidMount、类方法AIChatDrawer、InputArea
function Xxx()重点看 return、useState、useEffect一些新写的小组件

不要因为看到 class 就以为它过时不能读。AIHom 里 class component 很多，能读懂它很重要。

5. 看到 hooks 先只认两个

hook小白版解释你要问的问题
useState组件自己记一个值这个值影响页面哪里？
useEffect组件加载后做一件事它是在请求数据、监听事件，还是清理资源？

6. 第一次进 ai-home，从这几个文件开始

文件作用先看什么
src/app/components/AIChatDrawer/AIChatDrawer.tsx聊天抽屉读 render() 里显示哪些区域
src/app/components/InputArea/index.tsx输入框看发送按钮、loading、排队提示
src/app/components/MainPage/index.tsx主页面看它组合了哪些大块组件
src/app/state.ts根状态下一课再细看

7. 读代码小练习

如果你想知道“输入框为什么显示 thinking...”，先不要全局乱搜。按这个路线：

  1. 打开 InputArea/index.tsx。
  2. 搜索 thinking 或 isLoading。
  3. 看 isLoading 是 props 传入，还是组件自己算出来。
  4. 如果是 props，回到父组件继续追。
Q1：Props 最接近什么？
  • A. 文件路径
  • B. 外部输入
  • C. 构建产物
  • D. 数据库表
Q2：JSX 主要告诉你什么？
  • A. 分支策略
  • B. 后端协议
  • C. 页面结构
  • D. 发布环境
Q3：按钮点击逻辑优先搜什么？
  • A. onClick
  • B. package
  • C. README
  • D. favicon
复习时可以问 agent：带我读 InputArea/index.tsx，只看 props、render、onClick 三件事。
