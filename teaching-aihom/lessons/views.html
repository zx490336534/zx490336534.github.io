二维和三维怎么共用一份状态

理解坐标、选择状态与版本在不同视图之间如何同步。

先看场景走一遍读代码复现失败动手练习自测

先看场景

RoomLab 的二维图和三维预览看的是同一批矩形家具。尺寸与位置属于领域模型，缩放或相机角度只属于各自视图。

领域模型：家具在哪里、尺寸是多少。这些事实和你用哪种角度看它无关。

走一遍

  1. 给对象稳定 ID；选中时跨视图共享 ID，不共享像素坐标。
  2. 统一领域单位，视图层做坐标转换。
  3. 先校验模型版本再派生场景；只在结果有效时替换旧场景。
合成示例 可折叠
{"revision":3,"items":[{"id":"chair-a","x":1.2,"y":2.1,"width":0.5}]}

第二遍 · 把代码读懂

代码拆解

二维图点中椅子，再旋转三维相机，哪一份数据应该变、哪一份绝不能变？

调用链

  1. 领域状态用同一单位储存家具与稳定编号。
  2. 二维图用像素比例投影，三维视图用空间轴投影。
  3. 两张视图把选中状态映射到相同家具编号。
  4. 相机、缩放等各自保存在视图状态，重画不修改领域布局。
JavaScript 示例 可折叠

可复制到 lesson.cjs，再运行 node lesson.cjs。

const assert = require('node:assert/strict');
const layout = Object.freeze({
  revision: 3,
  items: Object.freeze([Object.freeze({ id: 'chair-A', x: 1.2, y: 2.1 })])
});

function plan(model, scale, selected) {
  return model.items.map(item => ({
    id: item.id,
    point: [Math.round(item.x * scale), Math.round(item.y * scale)],
    selected: item.id === selected
  }));
}

function scene(model, camera, selected) {
  return {
    revision: model.revision,
    camera: { ...camera },
    objects: model.items.map(item => ({
      id: item.id, xyz: [item.x, 0, item.y], selected: item.id === selected
    }))
  };
}

const viewing = plan(layout, 100, 'chair-A');
assert.deepEqual(viewing[0].point, [120, 210]);
const rotating = scene(layout, { angle: 75 }, 'chair-A');
assert.equal(rotating.objects[0].selected, true);
assert.deepEqual(rotating.objects[0].xyz, [1.2, 0, 2.1]);
assert.deepEqual(plan(layout, 100, 'chair-A'), viewing);
assert.equal(layout.revision, 3);

一份领域布局，两份派生结果

领域里的 x、y 统一以米表示。二维 px = x × scale；这个示例规定三维把地面 y 放到 z 轴，把高度放到 y 轴。别隐去具体假设，混用比例或轴向会让联动在同样数据下出现偏移。

对象身份不要依赖列表位置

两张视图的排序可能不同，甚至有对象被裁剪。选择使用 chair-A 这种稳定标识；投影只根据 ID 涂高亮。全量布局发布后，若所选家具已不存在，交给选择层清掉有效选中，不要让列表中下一项自动继承。

两个层次的版本

布局版本来自领域，镜头角度来自当前视图。旋转相机后重建三维投影输入，检查二维输出与领域布局不受影响。若真正的渲染器异步初始化，应为投影作业记住布局版本；画面提交时丢掉旧作业结果。

复现失败

尺度混用
怎么触发：把米直接当像素绘图，再用每米 100 像素对照。
怎么判断：椅子二维坐标应是 (120, 210)，模型仍是 (1.2, 2.1)。
相机移动误改家具
怎么触发：旋转三维相机，再捕获二维投影和领域版本。
怎么判断：家具坐标与二维投影不变。
列表位置不一致
怎么触发：调换家具显示顺序后点选椅子。
怎么判断：两张图仍按 ID 高亮椅子，不会高亮列表里相同下标的另一物件。

写下这些测试断言

  • 两边的选中项标识相等，但二维点与三维点各遵守自己的投影。
  • 镜头变化不使领域版本增加。
  • 输入布局可冻结且不抛错，防止投影偷偷改领域对象。

这一课带走：四个字记住：共享模型。坐标投影和镜头状态留在视图层。

动手练习

在二维图选中椅子后，再拖动三维相机。确认选中对象不变、相机移动不会改变业务坐标。
